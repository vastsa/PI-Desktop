# Advisor

The advisor tool name is `plugin_pi_advisor_advisor`. It takes no parameters.

Call it when it is in your tool list:

1. Before substantive implementation.
2. When you believe the task is complete, after making deliverables durable.
3. When stuck or considering a change of approach.

Restate the advisor's key guidance in your next visible reply. Weight the advice seriously unless empirically contradicted. If evidence conflicts, call advisor once more rather than silently switching approach.
