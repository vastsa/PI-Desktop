PI-Desktop macOS first launch

This build is unsigned. After moving PI-Desktop.app to Applications, double-click
PI-Desktop-macOS-open.command (shown as Open PI-Desktop.command in the DMG) to
clear Apple's quarantine flag and launch the app.

If you prefer Terminal, run:

xattr -r -d com.apple.quarantine /Applications/PI-Desktop.app

Use the helper only for an app obtained from a trusted PI-Desktop source. It
targets only PI-Desktop in /Applications or ~/Applications and removes only the
quarantine attribute. Signed and notarized builds do not need it.
