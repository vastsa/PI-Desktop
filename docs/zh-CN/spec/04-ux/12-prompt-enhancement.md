# 可选的输入框文本操作

> **翻译说明：** 本页对应[英文源规格](/spec/04-ux/12-prompt-enhancement)。字段名与标识符保持原文；事实以英文版本为准。

## 1. 范围

输入框文本转换是由用户选择启用的插件贡献项。宿主不再内置提示词增强操作或设置卡，也不会默认安装提示词增强插件。用户需要从独立仓库或已配置的插件目录主动安装插件。

插件通过 `contributes.composerTransforms` 声明操作，并申请 `composer.transform` 权限。每个操作提供按钮标题和可选的撤销标题。只有插件已启用、已加载并获得该权限时，宿主才显示操作。转换逻辑、设置以及插件选择执行的模型请求都由插件负责。

## 2. 调用与数据边界

操作显示在输入框工具栏的模型选择器之后。只有用户明确选择操作时，宿主才调用插件回调。回调收到 `{ id, text, modelKey? }`：草稿文本，以及可用时的当前输入框模型标识。回调不会收到对话历史、会话标识、附件或文件路径。宿主会在调用前移除内联文件引用标记，并在成功后恢复这些引用。

文本转换不是 Agent 回合：不会发送消息、运行工具或写入转录。回调必须返回字符串。宿主将输入和输出限制为 100,000 个字符，使用插件调用超时；每次调用都会检查权限和 manifest 声明，并记录审计结果。插件缺失、操作未声明、权限被撤销、结果无效、超时或插件卸载时，草稿保持不变。

成功后，返回文本替换草稿，光标移到末尾。单步撤销可恢复转换前的精确草稿。用户编辑、发送或切换会话会使待处理结果及撤销状态失效；卸载插件会使待处理结果失效。较晚返回的结果不能覆盖新草稿或其他会话的草稿。

## 3. 提示词增强插件与设置迁移

独立的 `pi.prompt-enhancement` 插件提供原有提示词增强操作。其实现与设置位于插件仓库；宿主只提供通用输入框文本转换契约。只有用户安装并授权插件后，操作才会出现。

该插件首次加载时，Electron 会在调用插件 `onLoad` 之前，将有效的旧宿主偏好复制到插件私有设置。已有插件设置优先。一次性迁移会映射旧模型、思考级别和已启用的自定义模板；无效或未启用的模板会跳过。私有迁移标记可防止用户之后清除插件设置时再次导入。为支持回退和降级，宿主保留旧值；迁移后 Composer 和设置页不再读取它们。

迁移仅针对该插件，不会默认安装插件。未安装插件时，宿主不会显示提示词增强操作或相关设置界面。
