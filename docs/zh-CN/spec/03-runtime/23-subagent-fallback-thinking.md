# 23. 子智能体备用模型的思考强度

> **翻译说明：** 本页是与 [英文源规格](/spec/03-runtime/23-subagent-fallback-thinking) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

备用模型条目可在 `provider/model` 后附加 `|off`、`|minimal`、`|low`、`|medium`、`|high`、`|xhigh` 或 `|max`。备用模型编辑器只提供这些固定级别，不提供 `omit`。未附加后缀时，继承子智能体定义的思考强度；定义未设置时继承父会话的选择。为兼容旧配置，仍可读取现有的 `|omit`，但 UI 不允许选择它。

执行时，运行时会根据所选模型支持的推理能力限制请求级别。后缀表示请求值，不保证每个 provider 都支持该精确级别。
