# ADR: Device confirmation grants access to all local LAN WebUI projects

- Status: Superseded by [One-time code pairing](lan-webui-code-pairing.md)
- Date: 2026-11-26

## Context

Individual project allowlists made pairing depend on a second selection.

## Decision

The original decision shared all local projects after a separate confirmation.
It is superseded by [One-time code pairing](lan-webui-code-pairing.md).

## Consequences

See the [LAN WebUI MVP](../spec/01-product/03-lan-webui-mvp.md) for current behavior.
