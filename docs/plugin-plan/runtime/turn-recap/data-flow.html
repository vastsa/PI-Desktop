status: draft · issue #561 · 权限 runtime.turn.recap · 会话范围另需 runtime.session.read

1接口约定 建议

无界面接口，runtime.turn.recap（high）。拉取式：插件调、宿主答、无推送。

// 只读这一轮的事实（无正文）
const r = await pi.recap({ scope: "turn" });

// 会话范围：最近消息行（需另授 runtime.session.read）
const s = await pi.recap({ scope: "session" });
方面内容权限
turn该轮事实：状态、token、provider/model、工具计数、动过的文件；正文 = nullruntime.turn.recap
session最近消息行（默认 200，封顶 500）+ truncated+ runtime.session.read
