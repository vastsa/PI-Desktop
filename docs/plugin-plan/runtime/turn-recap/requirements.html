turn-recap · 需求

读回顾：这一轮的事实，或（有权时）会话里最近的消息行。拉取式，插件主动调。

status: draft · issue #561 · 权限 runtime.turn.recap · 会话范围另需 runtime.session.read

范围 已核实

  • 只管「读回顾」：这一轮的事实摘要，或会话里最近的消息行。
  • 不谈：实时事件（turn-watch）、结构化事实（turn-facts）、压缩（session-lifecycle）。

现状（代码核实） 已核实
