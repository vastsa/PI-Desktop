session.getContext · 需求描述

status: draft · 设计稿 · 会话数据契约 · 规划出处：能力清单审查 N3 · 权限 session.context.read（新增） · 尚无 SDK 实现

1用途与边界

读当前话话的全量上下文工作集：system prompt、自上次压缩以来的消息与整体 token 估算，供 DIY 压缩器与上下文体检面板使用。

pi.session.getContext(input?: { sessionId?: string; scope?: "all" | "sinceCompaction"; maxCharsPerMessage?: number }): Promise<PluginSessionContext>

权限：session.context.read（新增 · high · 装时确认——能读消息正文，比 session.read 宽）。

2典型场景

场景插件做什么
DIY 压缩器（主场景）读 sinceCompaction 工作集 → 自算摘要 → 交 session.applyCompaction 写回。
上下文体检面板读 scope:"all"，展示 token 构成、压缩水位、消息分布。
压缩前检查在 before_compact 拦截后重读工作集，决定放行还是自己接手。

3明确不做什么

不提供消息写回与替换（写侧走 session.applyCompaction）；工具结果只给预览不吐全文；缺省只读当前话话，跨话话需显式 sessionId（同权限）。

4已拍板

  • 权限开新域 session.context.read（high，装时确认），不借用 session.read。
  • 缺省 scope 为 sinceCompaction，对齐压缩主场景；体检场景显式传 "all"。
  • 使用前提：实现时须放开现有 session.getLlmContext「仅工具执行期可调」的时机限制，改为纯权限门控。
