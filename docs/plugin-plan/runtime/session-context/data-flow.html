session.getContext · 数据流

status: draft · 设计稿 · 会话数据契约 · 规划出处：能力清单审查 N3 · 权限 session.context.read（新增） · 尚无 SDK 实现

1接口约定

pi.session.getContext(input?: { sessionId?: string; scope?: "all" | "sinceCompaction"; maxCharsPerMessage?: number }): Promise<PluginSessionContext>

读当前会话的全量上下文工作集。权限 session.context.read（新增 · high · 装时确认——能读消息正文）。

入参

字段类型必填说明
sessionIdstring否缺省 = 当前会话；跨会话读需显式指定（同权限）。
scope"all" | "sinceCompaction"否缺省 sinceCompaction：只回自上次压缩以来的工作集；"all" 回全量。
maxCharsPerMessagenumber否单条正文截断上限；缺省走宿主默认。截断发生时该条 contentTruncated = true。

出参

字段类型说明
sessionIdstring快照所属会话 id。
compactionCursorstring | null最近一次压缩记录 id；applyCompaction 并发校验（CONFLICT 检测）用。
systemstring | undefined当前 system prompt；无则缺省。
messagesArray<{…}>消息数组，元素结构见下。
messages[].idstring消息 id。
messages[].role"user" | "assistant" | "tool"角色；system 单独出 system 字段。
messages[].contentstring正文；超预算被截断时 contentTruncated = true。
messages[].contentTruncatedboolean | undefined该条是否被截断。
messages[].createdAtstringISO 时间字符串，与 session.listMessages 一致。
messages[].tool{…} | undefined工具消息的元信息：name / callId / status("success"|"error") / resultPreview（只给预览，不吐全文）。
estimate{ tokens: number; truncated: boolean }整体 token 估算；truncated 表示是否触发整体预算截断（只回窗口内）。
modelKeystring | undefined会话当前绑定的模型（provider/model）。

{ "scope": "sinceCompaction", "maxCharsPerMessage": 4000 }

一句话边界。能读正文，所以权限比 session.read 宽；工具结果只给 resultPreview，不吐全文。使用前提：实现时须放开现有 session.getLlmContext「仅工具执行期可调」的限制，改为纯权限门控——压缩发生在轮边界，不在任何工具调用里。

2数据怎么走

  1. 调用。插件传入可选 { sessionId?, scope?, maxCharsPerMessage? }。
  2. 校验。主进程校验 session.context.read 权限（装时确认过的高敏域），解析目标会话。
  3. 组装。宿主取会话全量消息与最近压缩记录（数据源与 session.getLlmContext 同链），按 scope 裁剪：压缩点之前的行并入摘要语境；工具结果压成 resultPreview；按整体预算与单条上限截断。
  4. 返回。一次给全；不订阅、不推流。超预算不报错，靠 estimate.truncated 如实标注。
方向内容
插件 → 宿主读取描述（scope、单条截断上限、目标会话）。
宿主 → 插件上下文快照（system + 消息 + 估算 + 压缩位点）。

3出错怎么办

情况结果码
未声明 session.context.readPromise 拒绝，不静默PERMISSION_DENIED
sessionId 不存在 / 已删Promise 拒绝NOT_FOUND
参数非法（未知 scope 等）Promise 拒绝INVALID_ARGUMENT
内容超整体预算不报错；只回窗口内，estimate.truncated = true—

4不提供什么

不给为什么
消息写回 / 替换写侧只走 session.applyCompaction；replaceMessages 静默改写已被产品排除
工具结果全文只给 resultPreview；全量正文不向插件开放
跨会话缺省读缺省当前会话；跨会话需显式 sessionId（同 high 权限）
精确 token 口径estimate 是估算值，与 ADR 0047 的口径对齐
