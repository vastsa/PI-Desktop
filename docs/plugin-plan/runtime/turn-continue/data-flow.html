turn-continue · 数据流

一条消息从插件到宿主队列、再变成一轮署名续跑的路径。六节固定：接口约定 / 数据怎么走 / 出错怎么办 / 不提供什么 / 相关条目 / 还没定的事。

status: draft · issue #561 · 权限 runtime.turn.continue · 走 queuePush · 插件署名可见

1接口约定 建议

无界面接口，runtime.turn.continue。入队即返回，不等工作跑完。带插件署名。

// 入队一条插件署名的续跑消息
const r = await pi.continueTurn({ message: "继续处理剩下的文件" });
// 对话里出现插件署名的排队行；轮按队列顺序跑
方面内容
入参{ message }
返回{ queuedTurnId }
署名宿主补 { pluginId, pluginLabel } 落库——行以插件名义可见
配额现状无上限
权限runtime.turn.continue，装时确认

4不提供什么 已核实

不给为什么
无署名续跑可见性是前提，不存在隐藏通道
用户身份冒充署名由宿主补，插件伪造不了
改历史消息只入新行
无限静默连跑无配额靠可见性兜底；静默连跑被禁止
