status: draft · issue #561 · 权限 runtime.turn.closing · 续跑走 agent.steer · 缺插件署名（缺陷）

1接口约定 建议

无界面钩子，runtime.turn.closing。轮末被动询问。

// 轮末：宿主问要不要续
pi.on("turn_closing", async () => {
  if (needMore()) return { continue: true, message: "还有两项未完成，请继续" };
  return { continue: false };
});
// 续跑：agent.steer({ role: "user" }) 注入——无插件署名（缺陷）
方面内容
输入轮末上下文（薄）
输出继续（可带建议消息）/ 不续
续跑通道agent.steer({ role: "user" })
署名无（缺陷）——有署名的是 turn-continue → queuePush
预算每次运行最多续若干轮（现值 4）
权限runtime.turn.closing

一次续跑的一生

时刻发生什么
收束前宿主发出轮末询问
插件建议继续（可带一条消息）或不续

续跑路径缺署名。steer 注入的是匿名 user 消息；用户看不出插件建议过续跑。有署名的是 runtime/turn-continue/ 的 queuePush。文档互为对照。

3出错怎么办 已核实

情况结果靠什么保证
多个插件 continue第一个生效，其余忽略裁决规则
预算用尽不再续，正常收束续跑上限（现值 4）
插件抛错视为不续 + 诊断运行器隔离
超时视为不续结果性询问的预算
沙箱插件目前收不到ADR 0300

4不提供什么 已核实

不给为什么
插件署名（当前）缺陷：steer 路径不带署名——不是故意不给，是对齐 queuePush 前的缺口
改历史消息只能建议再跑，不能改写已有行
无限续跑有预算
写权限轮末只出建议
