1接口约定 建议

无界面接口，权限 runtime.turn.abort，风险 high。

// 请求中止正在跑的这一轮
const ok = await pi.requestTurnAbort();
// ok === true  受理
// ok === false 拒绝 / 无权限（有诊断）

一次中止的一生

时刻发生什么
调用插件发出中止请求（无原因、无范围）
门控无权限 → false + 诊断；有权限继续
受理宿主停掉当前轮：不再发模型请求，工具调用尽量收尾
返回true / false 回到插件

3出错怎么办 已核实

情况结果靠什么保证
无权限返回 false + permission_denied 诊断权限门控
没有轮在跑返回 false（或 true 表示无事可做——见拍板）宿主状态
宿主拒绝返回 false + 诊断内核路径
沙箱插件目前收不到 / 调不通ADR 0300

4不提供什么 已核实

不给为什么
中止原因字段当前契约无载荷；要不要加见拍板
跨会话中止只针对当前轮
排队撤销队列是输入区 / 宿主的事
伪装用户停止中止来源是插件，不可冒充用户
