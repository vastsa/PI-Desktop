abort-turn · 需求

插件可以请求中止正在跑的轮。无入参，返回是否受理。风险 high，装时确认。

status: draft · issue #561 · 权限 runtime.turn.abort · 风险 high

范围 已核实

  • 只管「请求中止正在跑的这一轮」这一件事。
  • 不谈：发送前拦截（before-send）、队列撤销（输入区）、会话删除（session-lifecycle）。

明确不做 已核实

  • 不让插件伪造中止原因或伪装成用户点的停止。
  • 不做静默中止——refusal 返回 false 并记诊断。
  • 不中止别的会话——只针对当前轮。
  • 不管排队中的消息（那是队列的事）。

  • 要不要带用户可读原因；要不要区分中止范围。
  • 沙箱插件的接线通道（ADR 0300）未建——注册、预算、熔断都还没有。
