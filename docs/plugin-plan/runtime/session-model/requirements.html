session-model · 需求描述

status: proposal · 会话数据契约 · 出处：能力清单审查 N1 · 权限 session.read（沿用） · 尚无 SDK 实现

1用途与边界

查当前会话绑定的模型快照。事件 session:modelChanged 只推「变更」，插件冷启动/重载后没有初始值——本方法补上拉取侧，与事件成对（事件推增量、方法取全量）。

pi.session.getModel(): Promise<{ sessionId: string; modelKey: string | null; thinkingLevel: string | null; providerId?: string; modelId?: string }>

权限：session.read（沿用，只读不抬权）。

2典型场景

场景插件做什么
当前模型徽章状态栏渲染 provider/model · thinking；启动取快照，之后监听 session:modelChanged 刷新。
补全前对齐调 agent.complete 做自家摘要/改写前读当前模型，保持与主对话风格一致（也可直接省略 modelKey 走宿主默认）。
用量归因展示用量面板把每轮 providerId/modelId 与当前模型徽章联动展示。

3明确不做什么

不提供改模型（改模型走会话绑定 / 受信 setModel）；无活动会话不报错（返回 null 字段）；只读快照，无订阅语义（订阅用既有事件）。

4已拍板

  • 权限沿用 session.read，不开新域——模型绑定不是敏感面。
  • 返回 sessionId，与 session:modelChanged 事件配对时可直接对齐。
  • providerId / modelId 是 modelKey（provider/model）的拆解便利字段，宿主保证一致。
