1接口约定

pi.session.getModel(): Promise<{ sessionId: string; modelKey: string | null; thinkingLevel: string | null; providerId?: string; modelId?: string }>

查当前会话绑定的模型快照。权限 session.read（沿用，只读不抬权）。

入参

无入参。

出参

字段类型说明
sessionIdstring快照所属会话 id；与 session:modelChanged 事件配对用。
modelKeystring | nullprovider/model；无会话或未绑定时为 null。
thinkingLevelstring | null当前思考档位；未设置时为 null。
providerIdstring | undefinedmodelKey 的拆解便利字段。
modelIdstring | undefinedmodelKey 的拆解便利字段。

输入样例

// 无入参
pi.session.getModel()

输出样例

{
  "sessionId": "s_01J8",
  "modelKey": "anthropic/claude-sonnet-4-5",
  "thinkingLevel": "medium",
  "providerId": "anthropic",
  "modelId": "claude-sonnet-4-5"
}
一句话边界。只读快照、不提供改模型；与 session:modelChanged 成对使用——事件推变更、本方法取快照。无活动会话时 modelKey / thinkingLevel 为 null，不报错。

2数据怎么走

  1. 调用。插件无参调用。
  2. 校验。主进程校验 session.read 权限。
  3. 执行。宿主读当前会话的模型绑定与思考档位（会话态，无 IO）。
  4. 返回。一次给全；不订阅、不推流。
方向内容
插件 → 宿主无（纯查询）。
宿主 → 插件模型快照（sessionId + modelKey + thinkingLevel + 拆解）。

3出错怎么办

情况结果码
缺 session.read 权限Promise 拒绝，不静默PERMISSION_DENIED
无活动会话 / 未绑定模型不报错；返回 null 字段—

4不提供什么

不给为什么
改模型 / 改思考档位改绑定走会话绑定 / 受信 setModel；插件侧只读
订阅语义变更推送已有 session:modelChanged；本方法只取快照
跨会话查询只答当前会话；历史轮的模型归因走 usage.listTurns 行字段
