12 个事件清单

事件含义
agent_start一次运行开始
agent_end一次运行结束
agent_settled运行收束、状态稳定
turn_start一轮开始
turn_end一轮结束
message_start一条消息开始
message_update一条消息内容更新（流式）
message_end一条消息结束
tool_execution_start一次工具调用开始
tool_execution_update一次工具调用过程更新
tool_execution_end一次工具调用结束
after_provider_response模型一次应答之后

3出错怎么办 已核实

情况结果靠什么保证
插件没订阅事件直接丢掉无订阅者即无投递
插件处理慢不等它；宿主继续跑fire-and-forget
插件抛错记诊断，事件流不断运行器隔离
丢事件不补、不重投非结果性语义（{ADR_SLOTS_ONCE}）
沙箱插件目前收不到ADR 0300
