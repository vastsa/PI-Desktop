3出错怎么办 已核实

既然不开放，也就没有「插件抛错 / 超时 / 改写落库」这些路径。运行器会拒绝该事件并记诊断，防止旧插件静默失效而不自知。

4不提供什么 已核实

不给为什么
请求体改写永久（本轮）排除——含 message_list、工具列表、系统提示
model / think 覆盖归会话绑定，不归请求钩子
历史裁剪 / 摘要归宿主压缩，插件可在 session-lifecycle 的 before_compact 否决，但不能改写历史
取消请求归 abort-turn
