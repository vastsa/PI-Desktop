status: draft · issue #561 · 权限 runtime.tool.extend · addedToolNames / usage / terminate

1接口约定 建议

不是一个调用，而是插件自有工具返回值上的三个可选字段；宿主按 runtime.tool.extend 授权决定收下还是剥掉。

// 插件自有工具的返回值（示意）
return {
  ...normalResult,
  addedToolNames: ["my-next-step"],
  usage: { costUsd: 0.02 },
  terminate: true,
};
方面内容
addedToolNames引入新工具；界面署名插件；无授权 → 剥离 + 审计
usage报告花费；无授权 → 剥离 + 审计
terminate请求批量终止；无授权 → 剥离 + 审计
权限runtime.tool.extend；refusal / 剥离都留审计

3出错怎么办 已核实

情况结果靠什么保证
无授权三字段剥离 + 审计，结果照常字段级门控
addedToolNames 重名拒绝注册 + 审计命名冲突检查
terminate 无授权不终止门控
沙箱插件目前调不通ADR 0300

4不提供什么 已核实

不给为什么
改宿主工具结果那是 tool-gate 的只读边界
覆盖内建工具名重名拒绝注册
静默提权没授权就是剥离 + 审计
整轮中止语义terminate 是批量收工；整轮停走 abort-turn
