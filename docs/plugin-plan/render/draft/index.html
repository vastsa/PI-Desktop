为什么没有 demo

接口类，省略 demo。本目录钉的是调用契约，没有可挂载的界面槽。输入框和记号长什么样，见 ui/composer/demo.html；草稿方法在那里的场景 5 / 7 / 4 以文字说明出现，不另做界面演示页。

一句话回顾

  • readDraft → { text, marks[] }（带 generation 世代号，给替换对账用）。
  • insertText 是主路径：往光标处插一段文字，谁都能用、随时能用。
  • replaceDraft 受限：三道闸——世代号对账（CAS expectedGeneration）+ 输入框非聚焦才可写 + 远端来源禁止。
  • 草稿变化宿主 推给插件（rendererData draft），插件不要轮询。
  • 出站分层：insertText 属核心 H；readDraft 属可选 H；远端 replaceDraft 属拒绝。

还没定的事

marks 的字段名（沿用旧 tokens 还是定稿 marks）、generation 溢出策略——见 data-flow.html「还没定的事」。
