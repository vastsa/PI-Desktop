为什么没有 demo

接口类，省略 demo。本目录钉的是转发契约与失败码，没有可挂载的界面槽。槽组件取数后怎么画，各 UI 槽自己的 demo 已覆盖；这里只保证「怎么取到数」。

一句话回顾

  • 链路：组件 dispatch("plugin.call") → 校验声明 → 跨进程 plugin/renderer/call（{pluginId, method, args}）→ 本插件 onRendererCall → JSON 应答。
  • pluginId 由宿主注入，不可自填——只能调自己，不能冒充别家。
  • 约束五件套：method 白名单、载荷 ≤64KB、QPS 限速、2s 超时、连续失败熔断 PLUGIN_CALL_DISABLED。
  • 失败码：PLUGIN_CALL_NO_HANDLER · UNSERIALIZABLE · TIMEOUT · …
  • 不能推流——一问一答，返回值必须能变成 JSON。
  • 出站分层：核心 P。

还没定的事

QPS 具体数值、熔断连续失败次数——见 data-flow.html「还没定的事」。
