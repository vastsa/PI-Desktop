为什么没有 demo

接口类，省略 demo。本目录钉的是入参与边界，没有可挂载的界面槽。附件区长什么样见 ui/composer/demo.html（场景 6 的加 / 列 / 移）；这里不重复界面。

一句话回顾

  • 入参只有三样：{ name, mimeType, content|token }——名字、类型、内容本体或取内容的凭证。
  • S1 红线：禁 path / file:// / URL 引用。不许只交一个地址让宿主去读盘或上网；裸路径附件直接拒绝。
  • 内容由宿主落进暂存区，插件不再自己保管地址。
  • list 只见自己加的；remove 只能动自己加的。用户和别家的碰不到。
  • 出站分层：attachments.add 核心 H；list / remove 可选 H；裸路径附件拒绝。

还没定的事

token 的具体形态（一次性凭证还是宿主句柄）、暂存区大小上限——见 data-flow.html「还没定的事」。
