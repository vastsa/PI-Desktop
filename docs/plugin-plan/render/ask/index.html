为什么没有 demo

接口类，省略 demo。本目录只钉契约（入参、返回、边界），没有可挂载的界面槽。卡片长什么样，见 ui/layers/demo.html 的确认卡一幕（原 ui.confirm 形态，外形不变，只改返回值与名字）。

一句话回顾

  • 名字是 ui.ask（已定名，原 ui.confirm）——与 agent 侧的布尔确认同名不同物，改名消歧。
  • 返回恒为对象 { choice, reason? }，禁止「有时字符串、有时对象」两态。
  • 卸载时 reason: "plugin-unloaded"，挂起的等待一并落定，不悬空。
  • 卡壳宿主固定；按钮配置化（文案、档位）。卡片里没有插件代码在跑。
  • 不接管宿主的权限审批卡——那张卡是安全决策面，永远只属于宿主。
  • 出站分层里属可选 H。
