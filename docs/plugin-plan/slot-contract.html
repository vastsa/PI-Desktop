组件插槽公共契约

所有 UI 插槽共用的一套词与规则。各槽页只写自己的增量。

status: finalized · 引用代码写 分支@sha · 路径 · 符号，不用裸行号

1认领与冲突

类型槽冲突语义
additive 左右位user-action（userAction） · assistant-action（assistantAction）按注册顺序叠；无抢注
additive 追加位entry-extra（entryExtra，仅 AI 回复）多插件叠放；无抢注
自有工具卡tool-card无认领：只画自己注册的工具
keyed 语言block-renderer前缀:语言；不得注册已有语言
若出现替换型槽位，冲突码统一 PLUGIN_SLOT_DUPLICATE（先占者赢）。本轮 UI 槽无替换型。

2Props 骨架

字段含义
message这条消息的数据
messageId · sessionId标识
position?左右位："left" | "right"

action / entryExtra 槽不提供任何宿主函数与额外数据面。副作用走 dispatch。

3递交模型与出站词表

模型契约用在哪
props-once一次给全；重挂载才更新块渲染（闭合后）
核心 Hcomposer.acceptTriggerItem触发符候选选中项回流（label + value）；宿主写入 #label 记号；菜单未开拒绝 PLUGIN_ACTION_UNROUTED
props-once一次给全；重挂载才更新块渲染（闭合后）
props-push宿主推整份，插件不订阅action · entryExtra · 工具卡
request问几次答几次触发符候选
层词约束
核心 Hentry.copy · message.mutate · composer.insertText · attachments.addmutate 宿主确认+必审计；add 只收 content|token
核心 Pplugin.call白名单 · ≤64KB · QPS · 2s 超时熔断 · pluginId 宿主注入
核心 FmeasureHeight · deriveSummary同步纯函数 · 禁 I/O · 超时回默认 · F 内禁 H/P
可选 Hui.toast · ui.ask · clipboard.write · host.open · composer.readDraft · attachments.list/removeclipboard 同次手势；host.open 只认登记句柄
拒绝远端来源 replaceDraft · modal/overlay 四动作 · 裸路径附件P 返回不得静默改用户数据
F = 渲染线程内同步纯函数；H/P = 跨进程异步 dispatch。组件出站唯一出口是 dispatch + 词表。

4回退与出错归属

情况结果
additive 组件抛错只塌掉自己那一块
未加载 / 卸载位置释放
工具失败是数据不是抛错
宿主保证：出错隔离；卸载摘注册与注入样式。
已接受代价：同 realm 可碰全局；样式重写可被绕过；声明校验不是安全边界。

5权限

纯展示槽随 renderer.extension。副作用按词表声明并配权限。

6定稿记录（已定稿）

  • SDK 槽名已定稿：userAction / assistantAction / entryExtra；各槽页只链接本契约，不复述
  • 注册走统一判别式联合：{ slot: "userAction" | "assistantAction" | "entryExtra" | "toolCard", ... }；toolCard 项须带 toolName 且命中 manifest contributes.agentTools[].name
  • 左右位（userAction / assistantAction）每侧最多 3 个可见项，第 4 个起进宿主「⋯」折叠菜单；entryExtra 单块折叠态 320px / 展开态 600px 内部滚动
  • composer 触发符固定 @ / # / /；记号单草稿上限 8 个；tool-card 运行中 500ms 节拍合并推送（状态跃迁立即推）
  • ui.ask 定名不变：与 agent 侧布尔确认同名不同物，消歧表述以 render/ask 为准
  • SDK 与宿主已实现（7 槽 + self-dialog 指导项；dispatch 词表 plugin.call / composer.insertText / composer.acceptTriggerItem）；示例见 examples/plugins/ui-slots-lab，契约测试见 apps/desktop/test/plugin-*.test.mjs
