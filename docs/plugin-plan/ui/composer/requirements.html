输入区 · 需求

只写组件槽：左右控件、触发符、记号。固定件归宿主。草稿读写 / 附件方法不在本夹。

status: finalized · 本轮拍板见文末

范围 已定

  • 输入框工具栏的左右控件插件位。
  • 打触发符弹出的列表。
  • 输入框里的记号。
  • 不谈：草稿读写、附件方法（见 render/draft/、render/attachments/）、发送流程、固定件内部。

槽形状 已定

固定件归宿主。附件、模式切换、权限切换、模型选择、发送 / 停止插件碰不到。插件只做组件槽。
槽位置插件能做什么
左控件左排固定件右边加自己的按钮 / 弹层
右控件模型选择左边加自己的按钮
触发符输入框上方弹出的列表注册一个触发符号，提供列表内容
记号输入框内的记号选中项在草稿里长什么样

插件能拿到什么 已定

  • 组件槽的位置与渲染环境
  • 触发符：筛选文字；记号：label / send 数据
  • 不提供固定件的控制权

插件场景 已定

场景装上插件之后
左排加知识库选择固定件右边多一颗按钮
打 # 弹列表触发符列表，选中插记号
常用语左排按钮，点选插入片段

明确不做 已定

  • 固定件不可隐藏 / 替换 / 重排 / 插队
  • 草稿读写、附件方法不在本夹
  • 附件只收 content|token，禁 path / URL ref
  • markdown transformer 不做

问题决定
本夹写什么只写组件槽：左右控件、触发符、记号
固定件归宿主
草稿读写 / 附件方法不在本夹，见 render/draft/、render/attachments/
附件入参只收 content|token，禁 path / URL ref
定稿：触发符固定 @ / # / / 三个（一符一插件，重复注册返回 PLUGIN_SLOT_DUPLICATE；行首或空白后、非 IME 组词中才触发，程序写入永不触发）；记号单草稿上限 8 个，第 9 个起折叠为 ⧉ +N，发送 payload 不丢。
