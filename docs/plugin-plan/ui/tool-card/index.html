工具调用卡 · 目录

对话里每一次工具调用显示的那张卡。没有认领概念：插件只画自己注册的工具的卡片；宿主工具和别人工具不可定制。只展示，不交互。

范围、槽形状、插件能拿到什么、插件场景、明确不做、本轮拍板。

demo.html

自己的工具画成自己的卡；宿主 / 他人工具走默认卡；失败是数据。

data-flow.html

接口约定、数据怎么走、出错怎么办、不提供什么、相关条目、定稿记录。

六节固定

一句话回顾

  • 无认领：插件只画自己注册的工具；宿主 / 他人工具不可定制。
  • 展示不交互：卡上不做等待 / 审批 / 重试。
  • 失败是数据不是抛错：错误进结果字段，由插件画出来。
公共词表与规则见 slot-contract.html。
