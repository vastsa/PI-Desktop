工具调用卡 · 需求

对话里每一次工具调用显示的那张卡。插件只画自己注册的工具，展示不交互。

status: finalized · 本轮拍板见文末

范围 已定

  • 只谈对话流里工具调用卡的显示。
  • 本期只做展示：把这次调用的入参和结果显示好。
  • 不谈：工具执行本身、输入框上方的确认 / 审批、消息正文其他部分。

槽形状 已定

无认领概念。插件只画自己注册的工具的卡片；宿主工具和别人工具不可定制，永远走宿主默认卡。
  • 插件注册工具时一并给出卡片组件，这张卡只服务该工具的调用。注册走统一判别式联合 { slot:"toolCard", toolName, component }，toolName 须命中 manifest contributes.agentTools[].name。
  • 整卡自己画；不提供「只换头部 / 只换一半」的局部替换。

插件能拿到什么 已定

  • 这次调用的数据 — 工具名、入参、状态、结果
  • 各种 id — 调用 id、消息 id、会话 id
  • 结果里的失败信息是数据（字段），不是抛错
  • 不提供宿主函数与额外数据面

插件场景 已定

场景装上插件之后
自己的数据库查询工具结果画成 SQL + 表格
自己的统计工具结果画成条形图
调用失败错误是数据，由插件画成失败态

明确不做 已定

  • 无认领：不定制宿主工具、不定制别人工具
  • 展示不交互：不做下一步、审批、确认、重试再跑
  • 不让插件改入参、拦截或放行执行
  • 不让插件发起新的工具调用
  • markdown transformer 不做

本轮拍板 已定

问题决定
有没有认领没有。插件只画自己注册的工具；宿主 / 他人工具不可定制
展示还是交互只展示。等待 / 审批性质一律不做
失败怎么给失败是数据不是抛错，进结果字段由插件画
宿主 / 他人工具永远走宿主默认卡，一个字不变
定稿：卡片数据字段 toolName / toolCallId / toolArgs? / toolStatus / toolResult? / toolError? / durationMs?（复用 SDK 既有词表，失败即数据）；注册走统一判别式联合 { slot:"toolCard", toolName, component }；运行中 500ms 节拍合并推送整份 props，状态跃迁与最终结果立即推。
