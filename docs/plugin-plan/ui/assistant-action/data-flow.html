AI 回复操作栏 · 数据流

与用户消息操作栏同一套：props 一次给全，插件只渲染，不回调宿主。

status: finalized · 槽名与 props 字段名已定稿（见 slot-contract.html §6）；SDK 与宿主已实现，示例见 examples/plugins/ui-slots-lab

1接口约定 已定

插件注册左右两个组件槽。只渲染，不提供宿主函数。

props含义
message这条 AI 回复的数据
messageId / sessionId各种 id
position"left" | "right"

权限：随 renderer.extension（纯展示）。副作用走插件自己的 plugin.call。

2数据怎么走 已定

方向内容
宿主 → 插件props 一次给全；消息重渲染时整份重推
插件 → 宿主无
插件 → 自己交互由插件自理（可走 plugin.call）

递交模型：props-push。

3出错怎么办 已定

情况结果
插件组件抛错只塌掉本插件那一侧新增区
插件未加载 / 已卸载新增区消失，位置释放
插件按钮逻辑失败插件自理

4不提供什么 已定

  • 不提供任何宿主函数
  • 不提供改正文、整卡替换、额外数据
  • 不允许改 / 藏 / 删宿主键

宿主保证

出错隔离；卸载时摘掉注册与注入样式。

已接受代价

同 realm 可碰全局；样式重写可被绕过。
