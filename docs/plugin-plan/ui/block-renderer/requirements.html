块渲染器 · 需求

AI 回复正文里的代码块。前缀 + 语言注册，整块接管渲染。

status: finalized · 无数据流页（原因见「本轮拍板」）

范围 已定

  • 只谈 AI 回复正文里代码块怎么显示。
  • 不谈：消息正文其他部分、工具调用卡、markdown transformer。

槽形状 已定

前缀 + 语言。语言注册必须是 <pluginId>:lang；不得注册已有语言（json / ts / mermaid 及宿主高亮语言）。
  • 整块接管：头部、复制、错误提示都是渲染器自己的。
  • 没被注册的标签永远走宿主默认代码块。

插件能拿到什么 已定

  • props = {language, source} — 语言标签 + 代码块原文
  • 原文全量、不解析；内容格式是渲染器和模型之间的事
  • 无宿主函数、无别的数据

插件场景 已定

场景装上插件之后
demo:chart 画统计图JSON 数据画成柱状图
demo:csv 画表格CSV 文本画成表
渲染失败渲染器自己显示错误 + 源码

明确不做 已定

  • 不得注册已有语言（json / ts / mermaid 及宿主高亮语言）
  • 不提供宿主函数
  • 不递消息上下文、不让改写消息原文
  • 不做多块联动、不做半截渲染
  • markdown transformer 不做

本轮拍板 已定

问题决定
语言注册必须 <pluginId>:lang；不得注册已有语言
props{language, source}，无宿主函数
有没有数据流没有 data-flow.html。宿主只在渲染时交一次「language + source」，之后没有别的数据往来；复制、源码、错误提示都是渲染器自己的事
定稿：流式未闭合围栏整段回退宿主默认代码块（显示原始语言串、不高亮、可复制），闭合后下一帧 props-once 挂载插件块；高度自管，宿主唯一兜底 4000px，超过按渲染失败处理（回退宿主块显示源码）。
