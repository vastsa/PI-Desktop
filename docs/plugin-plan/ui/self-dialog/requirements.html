自理弹窗 · 需求

插件自理的全屏弹窗和角落浮层。无槽无注册；四条底线；Esc 不关安全层。

status: finalized · 无数据流页（原因见「本轮拍板」）

范围 已定

  • 弹窗（模态）与悬浮层（非阻塞）由插件自己画。
  • 不谈：宿主确认卡、宿主权限审批卡、工具调用卡。

槽形状 已定

无槽、无注册、自理。插件在自己的组件里用 position: fixed 自画。宿主不设槽、不注册、无抢注。

四条底线：

底线为什么
画在自己组件里不逃出样式作用域
卸载即消失禁用 / 卸载随组件树消失，宿主不用收拾
压不过宿主安全层权限审批 / 确认等安全层永远在上
插件之间后开在上宿主不仲裁

插件能拿到什么 已定

  • 没有槽、没有注册，也没有宿主给的 props。
  • 层的出现与消失就是普通组件的挂载与卸载。

插件场景 已定

场景装上插件之后
全屏向导插件自己画模态弹窗
角落通知插件自己画浮层

明确不做 已定

  • 宿主不做槽、不做注册、不做抢注仲裁
  • Esc 不关安全层；关闭只走明确的界面动作（✕）
  • 不让自理层压过宿主安全层

本轮拍板 已定

问题决定
有没有槽 / 注册无槽无注册，自理
四条底线画在自己组件里；卸载即消失；压不过宿主安全层；插件之间后开在上、宿主不仲裁
Esc不关安全层；关闭只走 ✕
有没有数据流没有 data-flow.html。宿主不经手任何数据——无槽无注册，没有接口、没有数据往来
