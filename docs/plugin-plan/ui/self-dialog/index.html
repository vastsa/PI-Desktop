自理弹窗 · 目录

全屏弹窗与角落浮层由插件自理：无槽、无注册。四条底线约束；Esc 不关安全层。

status: finalized · folder id self-dialog · 无数据流页（见下）

这个目录里有什么

requirements.html

范围、槽形状（无槽自理）、四条底线、插件场景、明确不做、本轮拍板（含无数据流页的原因）。

六段固定
demo.html

模态弹窗、角落浮层、Esc 不关安全层、卸载即消失。

只有界面，无解说段落
没有 data-flow.html。无槽无注册，宿主不经手任何数据——省略原因记在 requirements 的「本轮拍板」。

一句话回顾

  • 无槽、无注册、自理：插件在自己的组件里 position: fixed 自画。
  • 四条底线：画在自己组件里；卸载即消失；压不过宿主安全层；插件之间后开在上、宿主不仲裁。
  • Esc 不关安全层；关闭只走明确的界面动作（✕）。
