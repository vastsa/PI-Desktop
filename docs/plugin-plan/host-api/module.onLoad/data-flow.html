1接口约定

onLoad?: () => Promise<void> | void  // PluginModule 可选钩子

插件被加载或启用时，宿主调用一次的初始化钩子；无需声明任何权限。—

无入参。宿主 API 不经参数传入：插件进程在加载模块前已把宿主 API 挂到 globalThis.pi，钩子里直接用 pi.*。

出参

字段类型说明
（返回值）Promise<void> | void无返回值；可返回 Promise，宿主等待其完成（async 钩子）。

输入样例

// 宿主调用（无参数）
module.onLoad()

// 插件侧最小实现（pi 来自 globalThis）
async onLoad() {
  await pi.commands.register({ id: "greet", title: "打招呼", run: () => pi.ui.showToast("你好", "info") })
}

输出样例

// 无返回值
一句话边界。今天实现的是 onLoad / onUnload；其他生命周期钩子未必触发。

2数据怎么走

  1. 调用。宿主加载或启用插件时调用一次 onLoad，无参数。
  2. 执行。插件在钩子内通过 pi 注册命令、工具、服务等贡献点，注册随调用陆续生效。
  3. 返回。钩子返回 void 或 Promise<void>；宿主等 Promise 完成后再继续后续流程。
  4. 失败。钩子抛错只记日志，不拖垮宿主；插件注册的命令和工具在卸载时由宿主删除。
方向内容
宿主 → 插件调用信号；宿主 API 经 globalThis.pi 预置，不经参数传入。
插件 → 宿主经 pi 发出的注册请求；钩子本身无返回值。

3出错怎么办

无错误码。钩子抛错只记日志，不拖垮宿主。

4不提供什么

今天实现的是 onLoad / onUnload；其他生命周期钩子未必触发。
