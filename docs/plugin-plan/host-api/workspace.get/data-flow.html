1接口约定

pi.workspace.get(): Promise<{ path: string; name: string } | null>

读当前工作区主文件夹的路径与名称；无工作区返回 null 而不是抛错。权限：—。

入参

无入参。

出参

字段类型说明
pathstring主文件夹绝对路径；无工作区时整个返回值为 null。
namestring文件夹名。

输入样例

// 无入参

输出样例

{ "path": "C:\\work\\shop", "name": "shop" }
// 无工作区时：null
一句话边界。只给主文件夹一个值；不承诺多根项目的全部 roots（事件里可能带 projectId / roots）。

2数据怎么走

  1. 调用：插件无参发起。
  2. 读取：宿主返回当前工作区缓存值。
  3. 返回：有工作区给 { path, name }，无则 null。
  4. 跟踪变化：工作区切换经 workspace:changed 事件推送（用 events.on 订阅），需要时重新 get。

3出错怎么办

一般不失败。

4不提供什么

不承诺多根项目全部 roots（事件里可能带 projectId/roots）。
