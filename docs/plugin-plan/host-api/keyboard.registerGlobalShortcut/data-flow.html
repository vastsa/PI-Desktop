1接口约定

pi.keyboard.registerGlobalShortcut(input: { id: string; accelerator: string; command: string }): Promise<PluginGlobalShortcut>

把一个系统全局加速键绑定到本插件命令，宿主持有并做冲突检查。权限：—。

入参

字段类型必填说明
idstring是条目 id，本插件内唯一；同 id 再注册会替换加速键。
acceleratorstring是加速键串，如 CommandOrControl+Shift+X。
commandstring是要触发的命令 id，必须已通过 commands.register 注册。

出参

字段类型说明
idstring回显条目 id。
acceleratorstring回显加速键串。
commandstring回显命令 id。
registeredbooleanfalse 表示加速键被系统或其他持有者占用，未注册成功。
errorstring?注册失败原因，仅失败时出现。

输入样例

{ "id": "quick-open", "accelerator": "CommandOrControl+Shift+X", "command": "demo.hello.open-panel" }

输出样例

{
  "id": "quick-open",
  "accelerator": "CommandOrControl+Shift+X",
  "command": "demo.hello.open-panel",
  "registered": true
}
一句话边界。只能绑到本插件自己的命令；加速键被占用时不抢占，结果 registered: false，只能换键。无键盘钩子、无原始按键流。

2数据怎么走

  1. 插件提交 { id, accelerator, command }。
  2. 校验：command 必须已注册，否则拒绝（INVALID_ARGUMENT）；平台不支持则 UNSUPPORTED。
  3. 宿主经 Electron globalShortcut 向系统登记加速键，持续到注销或插件卸载；清单 contributes.globalShortcuts 声明的 default 条目在加载后也自动尝试。
  4. Promise 兑现为 PluginGlobalShortcut：失败不抛出，registered: false 且 error 带原因（码见第 3 节），被拒的重注册保留原绑定。
  5. 加速键触发时宿主执行 command 对应命令的 run。
方向内容
插件 → 宿主{ id, accelerator, command } 注册请求。
宿主 → 系统向操作系统登记/释放全局加速键（Electron globalShortcut）。
宿主 → 插件加速键触发时执行 command 对应的 run。

3出错怎么办

情况结果码
平台不支持全局快捷键Promise 拒绝UNSUPPORTED
入参缺字段或命令未注册Promise 拒绝INVALID_ARGUMENT
加速键已被其他程序占用Promise 兑现为 registered: falseSHORTCUT_CONFLICT
加速键当前不可用Promise 兑现为 registered: falseSHORTCUT_UNAVAILABLE
加速键串格式非法Promise 兑现为 registered: falseINVALID_ACCELERATOR
超出每插件 8 条上限Promise 兑现为 registered: falseLIMIT_EXCEEDED

4不提供什么

无键盘钩子、无原始按键流；不抢系统/宿主已占用加速键。

宿主保证 / 已接受代价：宿主保证：拿不到按键事件流。已接受代价：冲突时不会抢占，只能换键。
