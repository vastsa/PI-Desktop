1接口约定

pi.session.get(input: { sessionId: string }): Promise<PluginSessionGetResult>

读取一条本插件会话的元数据（标题、来源、项目/模型绑定、消息数），不含消息正文。权限：—。

入参

字段类型必填说明
sessionIdstring是本插件拥有的会话 id。

出参

字段类型说明
sessionIdstring会话 id。
titlestring当前标题。
sourcestring导入来源 namespace。
externalIdstring来源系统内的原始 id。
originKind"imported" | "created"导入会话或宿主内创建。
projectIdnumber | null绑定的宿主项目 id，未绑定为 null。
projectPathstring | null绑定的项目路径，未绑定为 null。
modelIdstring | null当前绑定模型 id。
providerIdstring | null当前绑定提供商 id。
history对象导入时的绑定快照：history.projectPath / history.modelId / history.providerId，均可为 null。
messageCountnumber会话内消息条数。
createdAtstring会话创建时间（ISO）。
updatedAtstring最近更新时间（ISO）。

输入样例

{ "sessionId": "imp_9f3a2c" }

输出样例

{
  "sessionId": "imp_9f3a2c",
  "title": "React 迁移讨论",
  "source": "wechat-export",

  "originKind": "imported",
  "projectId": 3,
  "projectPath": "C:\\work\\shop",
  "modelId": "claude-sonnet-4-5",
  "providerId": "anthropic",
  "history": { "projectPath": null, "modelId": "claude-sonnet-4-5", "providerId": "anthropic" },

}
一句话边界。只给元数据，不返回消息正文；要读消息用 session.listMessages。

2数据怎么走

  1. 调用：插件带着 sessionId 发起请求。
  2. 校验：宿主做归属检查——会话必须属于本插件声明的 sessionSources，否则拒绝。
  3. 读取：宿主取会话行、绑定历史快照与消息计数。
  4. 返回：一次性返回 PluginSessionGetResult，不含消息正文。
方向内容
插件 → 宿主{ sessionId } 查询请求。
宿主 → 插件会话元数据 PluginSessionGetResult。

3出错怎么办

情况结果码
会话不属于本插件（source 隔离）调用失败，无数据返回PERMISSION_DENIED
sessionId 不存在调用失败NOT_FOUND

4不提供什么

不返回消息正文（用 listMessages）。
