1接口约定

pi.clipboard.getHistory(): Promise<ClipboardHistoryEntry[]>

读宿主保留的剪贴板历史（权限：—；历史可能含敏感信息，权限为 clipboard.read）。

无入参。

出参

字段类型说明
（返回值）ClipboardHistoryEntry[]历史条目数组；数组元素结构是判别联合，见下列字段。
type"text" | "image"判别字段：文本条目或图片条目。
textstring仅 type: "text"：文本内容。
format"png" | "jpeg" | "webp"仅 type: "image"：图片格式。
dataUint8Array仅 type: "image"：图片字节。
width / heightnumber仅 type: "image"：像素尺寸。
capturedAtstring两种变体都有：捕获时间。

输入样例

// 无入参

输出样例

[
  { "type": "text", "text": "部署已回滚", "capturedAt": "2026-02-16T09:12:00.000Z" },
  { "type": "image", "format": "png", "data": [137, 80, 78, 71], "width": 640, "height": 400, "capturedAt": "2026-02-16T09:10:41.000Z" }
]
一句话边界。只读宿主保留窗口内的历史（30 天 / 500 条 / 256 MiB 上界），不轮询系统剪贴板；没有删除历史的 API。

2数据怎么走

  1. 调用：插件进程发起 pi.clipboard.getHistory()。
  2. 校验：宿主检查读侧权限（clipboard.read）。
  3. 执行：宿主返回自己保留的剪贴板历史快照，有界（30 天 / 500 条 / 256 MiB）；宿主不轮询操作系统剪贴板。
  4. 返回：条目数组一次给全，无游标、无分页；文本与图片条目按 type 判别。
方向内容
插件 → 宿主无入参，仅调用。
宿主 → 插件ClipboardHistoryEntry[]。

3出错怎么办

情况结果码
读侧权限不满足Promise 拒绝，不返回历史PERMISSION_DENIED

4不提供什么

当前表面没有删除历史 API。

宿主保证 / 已接受代价：宿主保证：历史有界（30 天 / 500 条 / 256 MiB），不轮询操作系统剪贴板。已接受代价：更早的历史拿不到。
