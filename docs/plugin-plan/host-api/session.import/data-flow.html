1接口约定

pi.session.import(input: PluginSessionImportInput): Promise<PluginSessionImportResult>

把一条外部会话写入宿主持久化为插件拥有的会话；source 必须是清单已声明的命名空间。权限：—。

入参

字段类型必填说明
sourcestring是来源 namespace，必须是 manifest contributes.sessionSources 里声明过的 id。
externalIdstring是来源系统内的唯一 id；重复导入同一 (source, externalId) 会被跳过。
titlestring是会话标题。
projectIdnumber | null否显式绑定宿主项目（由 pi.project.create 创建）；缺省不绑定。
projectPathstring | null否项目路径信息，可空。
modelIdstring | null否绑定模型 id，可空。
providerIdstring | null否绑定提供商 id，可空。
createdAtstring是原始会话创建时间（ISO）。
updatedAtstring是原始会话更新时间（ISO）。
messagesPluginSessionMessage[]是消息数组。元素按角色：user / assistant（content + createdAt，assistant 可带 modelId / providerId）；tool（content + toolName + toolCallId + toolStatus，可带 toolArgs / toolResult）。

出参

字段类型说明
sessionIdstring宿主会话 id（新建或已存在）。
importedboolean本次是否真正写入。
skippedboolean是否因已导入过而跳过。

输入样例

{
  "source": "wechat-export",
  "externalId": "wx-2026-0212-01",
  "title": "React 迁移讨论",
  "projectId": 3,
  "createdAt": "2026-02-12T08:30:00.000Z",
  "updatedAt": "2026-02-14T21:05:00.000Z",
  "messages": [
    { "role": "user", "content": "帮我看看这个报错", "createdAt": "2026-02-12T08:30:00.000Z" },
    { "role": "assistant", "content": "是依赖版本冲突，先升级 vite。", "createdAt": "2026-02-12T08:30:07.000Z", "modelId": "claude-sonnet-4-5", "providerId": "anthropic" }
  ]
}

输出样例

{ "sessionId": "imp_9f3a2c", "imported": true, "skipped": false }
一句话边界。只能写入自己声明过的 source；越权来源会被宿主拒绝，且导入受大小与频率限制。

2数据怎么走

  1. 调用：插件提交完整会话（元数据 + 消息数组）。
  2. 校验：source 必须在清单 sessionSources 声明内；消息结构、大小与频率限制不满足即失败。
  3. 执行：宿主把会话与消息持久化，归属记为本插件 source。
  4. 返回：sessionId 与 imported / skipped 结果。
方向内容
插件 → 宿主一条完整外部会话（PluginSessionImportInput）。
宿主 → 插件导入结果 { sessionId, imported, skipped }。

3出错怎么办

情况结果码
source 未声明或越权调用失败，不写入PERMISSION_DENIED
入参结构非法（缺字段 / 消息格式错）调用失败，不写入INVALID_ARGUMENT
超出单次导入大小限制调用失败，不写入LIMIT_EXCEEDED
导入频率超限调用失败，不写入RATE_LIMITED

4不提供什么

不能伪造其他 source；不能跳过声明列表。

宿主保证 / 已接受代价：宿主保证：source 越权导入被拒。已接受代价：导入有大小与频率限制。
