1接口约定

pi.fs.reveal(pathFromRoot: string): Promise<void>

在操作系统的文件管理器中显示一个已有可读文件。权限：—

入参

字段类型必填说明
pathFromRootstring是根相对路径，须指向已存在的可读文件；受读范围与拒绝列表约束。

出参

字段类型说明
（返回值）void无返回数据；resolve 即已交给文件管理器。

输入样例

await pi.fs.reveal("reports/周报.pdf");

输出样例

// 无返回（void）；resolve 即已在文件管理器中定位
一句话边界。只显示单个文件，不选中多个文件。

2数据怎么走

  1. 调用：插件传根相对路径。
  2. 校验：文件须已存在且可读；读范围与拒绝列表照常生效。
  3. 执行：宿主调用系统文件管理器，定位并选中该文件。
  4. 返回：resolve 即完成，无数据。
方向内容
插件 → 宿主根相对路径。
宿主 → 插件无数据（仅成功/失败）。
宿主 → 系统打开文件管理器并定位该文件。

3出错怎么办

情况结果码
缺少 fs.read，或路径不在读范围拒绝PERMISSION_DENIED
文件不存在拒绝NOT_FOUND

4不提供什么

不选中多个文件。
