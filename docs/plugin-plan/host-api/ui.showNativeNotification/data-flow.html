1接口约定

pi.ui.showNativeNotification(input: PluginNativeNotificationInput): Promise<PluginNativeNotificationResult>

显示系统原生通知，并回告是否真正展示；权限：—。

入参

字段类型必填说明
titlestring是通知标题。
bodystring否通知正文，可省略。

出参

字段类型说明
shownboolean是否真正展示；false 时插件可回退到 showToast。
permission"granted" | "denied" | "unknown" | "unsupported"展示时的通知权限状态。

输入样例

{ "title": "备份完成", "body": "共 128 个文件" }

输出样例

{ "shown": true, "permission": "granted" }
一句话边界。不带自定义按钮/回复框。

2数据怎么走

  1. 调用：插件进程传入 { title, body? }。
  2. 校验：清单缺 notify 权限时拒绝。
  3. 执行：宿主检查通知权限并发起系统通知，展示生命周期由系统管理。
  4. 返回：{ shown, permission }；点击通知不激活会话，也不进持久任务通知箱。
方向内容
插件 → 宿主{ title, body? }。
宿主 → 系统系统原生通知。
宿主 → 插件{ shown, permission }。

3出错怎么办

情况结果码
清单缺 notify 权限Promise 拒绝，通知不发出PERMISSION_DENIED

4不提供什么

不带自定义按钮/回复框。

宿主保证 / 已接受代价：宿主保证：点击不激活会话，不进持久任务通知箱。已接受代价：没有自定义按钮。
