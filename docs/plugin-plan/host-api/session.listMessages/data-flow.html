1接口约定

pi.session.listMessages(input: { sessionId: string; limit?: number; cursor?: string; order?: "asc" | "desc"; contentLimit?: number }): Promise<PluginSessionMessageListResult>

分页读取一条本插件会话的消息（角色、正文、工具调用），支持正/倒序与单条正文截断。权限：—。

入参

字段类型必填说明
sessionIdstring是本插件拥有的会话 id。
limitnumber否单页消息条数上限。
cursorstring否上一页返回的 nextCursor。
order"asc" | "desc"否按时间正序或倒序。
contentLimitnumber否单条正文最大长度，超出部分被截断。

出参

字段类型说明
itemsPluginSessionMessageResult[]本页消息。数组元素结构：id、role（"user"|"assistant"|"tool"）、content、contentTruncated?（true=正文被截断）、createdAt、origin（恒为 "external"）、tool?（仅 tool 消息：{ name, callId, status: "success"|"error", args?, result? }）。
nextCursorstring还有下一页时出现；否则缺省。

输入样例

{ "sessionId": "imp_9f3a2c", "limit": 50, "order": "asc", "contentLimit": 2000 }

输出样例

{
  "items": [
    { "id": "m_01", "role": "user", "content": "帮我看看这个报错", "createdAt": "2026-02-12T08:30:00.000Z", "origin": "external" },
    { "id": "m_02", "role": "assistant", "content": "看起来是依赖版本冲突，先升级……", "contentTruncated": true, "createdAt": "2026-02-12T08:30:07.000Z", "origin": "external" }
  ],
  "nextCursor": "bTFfMDI"
}
一句话边界。只能读本插件会话；contentLimit 会截断正文，截断时以 contentTruncated 标记。

2数据怎么走

  1. 调用：插件带 sessionId（可加 limit / cursor / order / contentLimit）。
  2. 校验：会话归属本插件、参数合法，否则 PERMISSION_DENIED / NOT_FOUND / INVALID_ARGUMENT。
  3. 执行：宿主按游标分页取消息，正文按 contentLimit 截断并打标。
  4. 返回：items + nextCursor，按 order 排序。
方向内容
插件 → 宿主会话 id 与分页/排序/截断参数。
宿主 → 插件消息页 { items, nextCursor? }。

3出错怎么办

情况结果码
会话不属于本插件调用失败PERMISSION_DENIED
sessionId 不存在调用失败NOT_FOUND
分页/排序参数非法调用失败INVALID_ARGUMENT

4不提供什么

不能读其他插件会话；contentLimit 可能截断正文。
