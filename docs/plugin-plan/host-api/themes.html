删除本插件的一条运行时主题；权限：—。

入参

出参

字段类型说明
（返回值）void无返回数据，成功即 resolve。

输出样例

// void —— 成功即 resolve，无输出
一句话边界。只作用于本插件注册表：不能删其他插件主题或内置主题。

2数据怎么走

  1. 调用：插件进程传入本地 themeId。

  3. 执行：立即从本插件注册表删除；若该主题正被使用，宿主回到默认主题。

1接口约定

pi.themes.setVariables(themeId: string, values: Record<string, number | string>): Promise<void>

写入主题的设计令牌变量值；权限：—。

入参

字段类型必填说明
themeIdstring是本插件本地主题 id（第一个位置参数）。
valuesRecord<string, number | string>是变量键值对（第二个位置参数）；只能写清单校验声明过的变量，值须为 number 或 string。

出参

字段类型说明
（返回值）void无返回数据，成功即 resolve。

输入样例

pi.themes.setVariables("forest", { "accent": "#40c977", "radius": 10 })

输出样例

// void —— 成功即 resolve，无输出
一句话边界。只接受声明白名单内的键；变量写在主题注册表上，随主题删除消失。

2数据怎么走

  1. 调用：插件进程按位置传 themeId 与 values。
  2. 校验：权限、主题存在性、变量键白名单与值类型，任一不过即拒绝。
  3. 执行：变量写入本插件主题注册表，随主题删除消失。
  4. 返回：resolve，无数据回传。

themes.upsertimplemented

status: implemented · 事实源 packages/plugin-sdk/src/index.ts · PluginHostApi

1接口约定

pi.themes.upsert(input: PluginThemeUpsertInput): Promise<void>

创建或更新本插件的一条运行时主题；权限：—。

入参

字段类型必填说明
idstring是本地主题 id，规则同 contributes.themes[].id；同 id 即更新。
labelstring是主题显示名。
base"light" | "dark"是明暗基调。
cssstring是CSS 正文；宿主按加载时规则消毒后生效。

出参

字段类型说明
（返回值）void无返回数据，成功即 resolve。

输入样例

{
   "id": "forest",
   "label": "森林",
   "base": "dark",
   "css": ":root{--bg:#0f1a12;--text:#d8e8dc;}"
 }

输出样例

// void —— 成功即 resolve，无输出
一句话边界。CSS 由宿主消毒，不能执行脚本；与 contributes.themes 互补。

2数据怎么走

  1. 调用：插件进程传入 { id, label, base, css }。
  2. 校验：权限、id 规则、base 取值与主题数量上限，任一不过即拒绝。
  3. 执行：CSS 按加载时规则消毒，然后注册到本插件运行时主题表（同 id 覆盖）；注册在插件进程，卸载后主题不可选。
  4. 返回：resolve，无数据回传。

3出错怎么办

情况结果码
权限域不满足Promise 拒绝，主题不注册PERMISSION_DENIED
字段非法（如 base 不是 light/dark、id 不合规）Promise 拒绝INVALID_ARGUMENT
主题数量超出宿主上限Promise 拒绝LIMIT_EXCEEDED

4不提供什么

CSS 由宿主按加载时规则消毒，不能执行脚本。
