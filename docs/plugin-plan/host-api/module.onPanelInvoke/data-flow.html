1接口约定

onPanelInvoke?: (channel: string, payload: unknown) => Promise<unknown> | unknown  // PluginModule 可选钩子

隔离面板页与插件之间的固定通道调用入口；面板能力不因该钩子扩大，无需声明任何权限。—

入参

字段类型必填说明
channelstring是通道名，由插件自己约定（固定通道，非通用 IPC）。
payloadunknown是面板页随调用携带的数据；可为空值，结构由插件约定。

出参

字段类型说明
（返回值）Promise<unknown> | unknown处理结果，结构由插件实现决定，原样回传面板页。

输入样例

// 宿主调用：转发面板页的固定通道调用
module.onPanelInvoke("submit", { title: "周报", count: 3 })

// 插件侧最小实现
onPanelInvoke(channel, payload) {
  if (channel === "submit") return { ok: true, saved: payload.title }
  throw new Error("未知通道: " + channel)
}

输出样例

// 返回类型为 unknown，结构由插件实现自定义
{ "ok": true, "saved": "周报" }
一句话边界。不是通用 IPC：通道语义由插件自己约定，宿主不借它暴露 plugin.setSettings、fs.remove 或任意 Electron IPC。

2数据怎么走

  1. 调用。面板打开期间（ui.openPanel 打开的隔离沙箱页），面板页经固定通道发起调用。
  2. 转发。宿主把通道名与数据转发给插件主模块的 onPanelInvoke；面板页是沙箱页，不直接访问插件进程。
  3. 执行。插件按 channel 分发处理，payload 结构由插件约定。
  4. 返回。处理结果（可 async）回传面板页；通道未处理按宿主错误模型返回。
方向内容
宿主 → 插件channel 通道名与 payload 数据。
插件 → 宿主处理结果，原样回传面板页。

3出错怎么办

无错误码。通道未处理时，按宿主错误模型返回给面板页。

4不提供什么

不是通用 IPC；通道由插件自己约定。

宿主保证 / 已接受代价：宿主保证：不暴露 `plugin.setSettings`、`fs.remove` 或任意 Electron IPC。已接受代价：通道由插件自己约定。
