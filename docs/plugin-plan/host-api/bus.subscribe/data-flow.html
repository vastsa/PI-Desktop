1接口约定

pi.bus.subscribe(topic: string, handler: (message: PluginBusMessage) => void): Promise<() => Promise<void>>

订阅声明过的主题模式，resolve 出一个取消订阅函数（权限：—；模式必须命中清单 contributes.bus.subscribe 声明）。

入参

字段类型必填说明
topicstring是主题模式：段可为 *（恰好一段）或 **（仅限末段，匹配一或多段）；最多 8 段、总长 ≤128。
handler(message: PluginBusMessage) => void是命中消息的回调；PluginBusMessage 含 topic / from / payload? / at。

出参

字段类型说明
（返回值）Promise<() => Promise<void>>resolve 为取消订阅函数；调用它（同样是异步）即停止接收该模式的推送。

输入样例

pi.bus.subscribe("notes.*", (message) => render(message.payload))

输出样例

// resolve 出取消订阅函数（() => Promise<void>）
const unsubscribe = await pi.bus.subscribe("notes.*", onMessage);
await unsubscribe(); // 此后不再收到 notes.* 的消息
一句话边界。不是持久队列：只收订阅之后的消息；取消用返回的函数，或等插件卸载时宿主清理。

2数据怎么走

  1. 调用：插件进程传入主题模式与 handler，await 返回的 Promise。
  2. 校验：模式必须合法（* 恰好一段；** 仅限末段）且命中清单 contributes.bus.subscribe 声明，否则 PERMISSION_DENIED。
  3. 执行：其他插件发布命中该模式的消息时，宿主把 PluginBusMessage（topic / from / payload? / at）推给 handler；只送订阅之后的消息。
  4. 结束：调用返回的取消函数（await），或插件卸载时宿主自动清理。
方向内容
插件 → 宿主订阅模式 + 处理函数。
宿主 → 插件PluginBusMessage（topic / from / payload? / at）。
