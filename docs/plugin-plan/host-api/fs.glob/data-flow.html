1接口约定

pi.fs.glob(pattern: string): Promise<string[]>

按 glob 模式列出规则根内匹配的根相对路径。权限：—

入参

字段类型必填说明
patternstring是根相对 glob（如 **/*.ts）；没有 pathFromRoot 参数。

出参

字段类型说明
（返回值）string[]匹配的根相对路径，可直接用于 fs.readText / fs.stat。

输入样例

const files = await pi.fs.glob("**/*.test.ts");

输出样例

["src/fs.test.ts", "src/policy.test.ts"]
一句话边界。只给路径不给正文；结果不是目录树导航，逐层看用 fs.list。

2数据怎么走

  1. 调用：插件传一个根相对 glob 模式（无 pathFromRoot 参数，作用域就是规则根）。
  2. 匹配：模式与 manifest.fs scope 共用同一套语义 —— ** 跨目录段，*/? 只在单段内；含 .. 的路径永不匹配；Windows/macOS 上忽略大小写。
  3. 过滤：结果只保留声明读范围允许、且未命中拒绝列表（.git、.env 等）的路径。
  4. 返回：匹配的根相对路径数组回给插件。
方向内容
插件 → 宿主glob 模式。
宿主 → 插件匹配的根相对路径数组。

3出错怎么办

情况结果码
缺少 fs.read拒绝PERMISSION_DENIED
模式不是合法的根相对 glob拒绝INVALID_ARGUMENT
匹配结果超过宿主允许的上限拒绝LIMIT_EXCEEDED

4不提供什么

不读正文；结果不是目录树导航（用 fs.list）。
