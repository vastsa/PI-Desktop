1接口约定

pi.session.importBatch(input: PluginSessionBatchImportInput): Promise<PluginSessionBatchImportResult>

一批导入同一 source 的多条外部会话，逐条返回结果并给出计数。权限：—。

入参

字段类型必填说明
sourcestring是整批共用的来源 namespace，须在清单 sessionSources 声明。
sessionsArray<Omit<PluginSessionImportInput, "source">>是会话数组；元素结构同 pi.session.import 入参去掉 source。
mode"skip" | "fail"否单条失败策略：skip 跳过该条继续，fail 整批失败。

出参

字段类型说明
results数组逐条结果。数组元素结构：externalId、sessionId（失败为 null）、status（"imported"|"skipped"|"failed"）、errorCode?、errorMessage?。
importednumber成功导入条数。
skippednumber跳过条数。
failednumber失败条数。

输入样例

{
  "source": "wechat-export",
  "mode": "skip",
  "sessions": [
    {
      "externalId": "wx-2026-0212-01",
      "title": "React 迁移讨论",
      "createdAt": "2026-02-12T08:30:00.000Z",
      "updatedAt": "2026-02-14T21:05:00.000Z",
      "messages": [ { "role": "user", "content": "帮我看看这个报错", "createdAt": "2026-02-12T08:30:00.000Z" } ]
    }
  ]
}

输出样例

{
  "results": [
    { "externalId": "wx-2026-0212-01", "sessionId": "imp_9f3a2c", "status": "imported" },
    { "externalId": "wx-2026-0212-02", "sessionId": null, "status": "failed", "errorCode": "INVALID_ARGUMENT", "errorMessage": "消息格式非法" }
  ],
  "imported": 1,
  "skipped": 0,
  "failed": 1
}
一句话边界。没有事务回滚：mode: "fail" 中止后，已导入的条目仍然保留。

2数据怎么走

  1. 调用：插件提交 source + 会话数组 + mode。
  2. 校验：source 必须已声明；整体入参非法直接失败（码同 import）。
  3. 执行：逐条走 session.import 的校验与持久化；单条失败按 mode 决定跳过或中止。
  4. 返回：逐条 status（失败条带 errorCode / errorMessage）与 imported / skipped / failed 计数。
方向内容
插件 → 宿主一批外部会话（共用 source）与失败策略。
宿主 → 插件逐条结果数组与三个计数。

3出错怎么办

情况结果码
source 未声明或越权调用失败，不写入PERMISSION_DENIED
入参结构非法调用失败，不写入INVALID_ARGUMENT
超出大小限制调用失败，不写入LIMIT_EXCEEDED
频率超限调用失败，不写入RATE_LIMITED
单条失败（按 mode 跳过或中止）该条 results[].status = "failed"，带 errorCode / errorMessage—（记入 results[].errorCode）

4不提供什么

不是事务回滚；mode: skip 会留下已导入的部分。
