1接口约定

pi.clipboard.writeText(text: string): Promise<void>

把一段文本写入系统剪贴板（权限：—；写侧权限独立，与读分离）。

入参

字段类型必填说明
textstring是要写入的文本，位置参数。

出参

字段类型说明
（返回值）void无返回数据，成功即 resolve。

输入样例

pi.clipboard.writeText("已生成的内容")

输出样例

// void —— 成功即 resolve，无输出
一句话边界。覆盖式写入系统剪贴板；不提供历史清理（历史读取另有 clipboard.getHistory）。

2数据怎么走

  1. 调用：插件进程传入 text。
  2. 校验：宿主检查写侧权限（与读分离）。
  3. 执行：宿主把文本写入系统剪贴板，覆盖原有内容。
  4. 返回：无回执值；写入结果由 resolve / reject 表达。
方向内容
插件 → 宿主文本字符串。
宿主 → 系统覆盖系统剪贴板。

情况结果码
