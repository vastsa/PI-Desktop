1接口约定

pi.session.delete(input: { sessionId: string; mode?: "trash" | "purge" }): Promise<{ deleted: boolean }>

删除一条本插件导入的会话；mode 区分回收与彻底清除。权限：—。

入参

字段类型必填说明
sessionIdstring是本插件拥有的会话 id。
mode"trash" | "purge"否trash=回收（可恢复策略见宿主），purge=彻底清除、不可恢复。

出参

字段类型说明
deletedboolean是否删除成功。

输入样例

{ "sessionId": "imp_9f3a2c", "mode": "purge" }

输出样例

{ "deleted": true }
一句话边界。只能删本插件的会话；purge 不可恢复，回收策略以宿主实现为准。

2数据怎么走

  1. 调用：插件提交 sessionId（可加 mode）。
  2. 校验：归属检查（session.delete.own）与 id 存在性。
  3. 执行：按 mode 回收或清除该会话数据。
  4. 返回：{ deleted }。

3出错怎么办

无 session.delete.own 或会话不属于本插件调用失败，数据不动PERMISSION_DENIED
sessionId 不存在调用失败NOT_FOUND
删除频率超限调用失败RATE_LIMITED

4不提供什么

不能删其他插件会话。

1接口约定

pi.session.import(input: PluginSessionImportInput): Promise<PluginSessionImportResult>

把一条外部会话写入宿主持久化为插件拥有的会话；source 必须是清单已声明的命名空间。权限：—。

入参

字段类型必填说明
sourcestring是来源 namespace，必须是 manifest contributes.sessionSources 里声明过的 id。
externalIdstring是来源系统内的唯一 id；重复导入同一 (source, externalId) 会被跳过。
titlestring是会话标题。
projectIdnumber | null否显式绑定宿主项目（由 pi.project.create 创建）；缺省不绑定。
projectPathstring | null否项目路径信息，可空。
modelIdstring | null否绑定模型 id，可空。
providerIdstring | null否绑定提供商 id，可空。
createdAtstring是原始会话创建时间（ISO）。
updatedAtstring是原始会话更新时间（ISO）。
messagesPluginSessionMessage[]是消息数组。元素按角色：user / assistant（content + createdAt，assistant 可带 modelId / providerId）；tool（content + toolName + toolCallId + toolStatus，可带 toolArgs / toolResult）。

出参

字段类型说明
sessionIdstring宿主会话 id（新建或已存在）。
importedboolean本次是否真正写入。
skippedboolean是否因已导入过而跳过。

输入样例

{
  "source": "wechat-export",
  "externalId": "wx-2026-0212-01",
  "title": "React 迁移讨论",
  "projectId": 3,
  "createdAt": "2026-02-12T08:30:00.000Z",
  "updatedAt": "2026-02-14T21:05:00.000Z",
  "messages": [
    { "role": "user", "content": "帮我看看这个报错", "createdAt": "2026-02-12T08:30:00.000Z" },
    { "role": "assistant", "content": "是依赖版本冲突，先升级 vite。", "createdAt": "2026-02-12T08:30:07.000Z", "modelId": "claude-sonnet-4-5", "providerId": "anthropic" }
  ]
}

输出样例

{ "sessionId": "imp_9f3a2c", "imported": true, "skipped": false }
一句话边界。只能写入自己声明过的 source；越权来源会被宿主拒绝，且导入受大小与频率限制。

2数据怎么走

  1. 调用：插件提交完整会话（元数据 + 消息数组）。
  2. 校验：source 必须在清单 sessionSources 声明内；消息结构、大小与频率限制不满足即失败。
  3. 执行：宿主把会话与消息持久化，归属记为本插件 source。
  4. 返回：sessionId 与 imported / skipped 结果。
方向内容
插件 → 宿主一条完整外部会话（PluginSessionImportInput）。
宿主 → 插件导入结果 { sessionId, imported, skipped }。

3出错怎么办

情况结果码
source 未声明或越权调用失败，不写入PERMISSION_DENIED
入参结构非法（缺字段 / 消息格式错）调用失败，不写入INVALID_ARGUMENT
超出单次导入大小限制调用失败，不写入LIMIT_EXCEEDED
导入频率超限调用失败，不写入RATE_LIMITED

4不提供什么

不能伪造其他 source；不能跳过声明列表。

宿主保证 / 已接受代价：宿主保证：source 越权导入被拒。已接受代价：导入有大小与频率限制。

5相关条目

  • host-api/session.importBatch
  • host-api/project.create

无。

status: implemented · 事实源 packages/plugin-sdk/src/index.ts · PluginHostApi

1接口约定

pi.session.importBatch(input: PluginSessionBatchImportInput): Promise<PluginSessionBatchImportResult>

一批导入同一 source 的多条外部会话，逐条返回结果并给出计数。权限：—。

入参

字段类型必填说明
sourcestring是整批共用的来源 namespace，须在清单 sessionSources 声明。
sessionsArray<Omit<PluginSessionImportInput, "source">>是会话数组；元素结构同 pi.session.import 入参去掉 source。
mode"skip" | "fail"否单条失败策略：skip 跳过该条继续，fail 整批失败。

出参

字段类型说明
results数组逐条结果。数组元素结构：externalId、sessionId（失败为 null）、status（"imported"|"skipped"|"failed"）、errorCode?、errorMessage?。
importednumber成功导入条数。
skippednumber跳过条数。
failednumber失败条数。

输入样例

{
  "source": "wechat-export",
  "mode": "skip",
  "sessions": [
    {
      "externalId": "wx-2026-0212-01",
      "title": "React 迁移讨论",
      "createdAt": "2026-02-12T08:30:00.000Z",
      "updatedAt": "2026-02-14T21:05:00.000Z",
      "messages": [ { "role": "user", "content": "帮我看看这个报错", "createdAt": "2026-02-12T08:30:00.000Z" } ]
    }
  ]
}

输出样例

{
  "results": [
    { "externalId": "wx-2026-0212-01", "sessionId": "imp_9f3a2c", "status": "imported" },
    { "externalId": "wx-2026-0212-02", "sessionId": null, "status": "failed", "errorCode": "INVALID_ARGUMENT", "errorMessage": "消息格式非法" }
  ],
  "imported": 1,
  "skipped": 0,
  "failed": 1
}
一句话边界。没有事务回滚：mode: "fail" 中止后，已导入的条目仍然保留。

2数据怎么走

  1. 调用：插件提交 source + 会话数组 + mode。
  2. 校验：source 必须已声明；整体入参非法直接失败（码同 import）。
  3. 执行：逐条走 session.import 的校验与持久化；单条失败按 mode 决定跳过或中止。
  4. 返回：逐条 status（失败条带 errorCode / errorMessage）与 imported / skipped / failed 计数。
方向内容
插件 → 宿主一批外部会话（共用 source）与失败策略。
宿主 → 插件逐条结果数组与三个计数。

3出错怎么办

情况结果码
source 未声明或越权调用失败，不写入PERMISSION_DENIED
入参结构非法调用失败，不写入INVALID_ARGUMENT
超出大小限制调用失败，不写入LIMIT_EXCEEDED
频率超限调用失败，不写入RATE_LIMITED
单条失败（按 mode 跳过或中止）该条 results[].status = "failed"，带 errorCode / errorMessage—（记入 results[].errorCode）

4不提供什么

不是事务回滚；mode: skip 会留下已导入的部分。

  • host-api/session.import

无。

updatedboolean标题是否更新成功。

输入样例

{ "sessionId": "imp_9f3a2c", "title": "0212 React 迁移" }

输出样例

{ "updated": true }
一句话边界。只能改本插件会话的标题；宿主会话与其他插件的会话不可改。

2数据怎么走

  1. 调用：插件提交 sessionId + 新 title。
  2. 校验：宿主检查会话归属（本插件 source）与 id 存在性。
  3. 执行：持久化新标题，list 与 get 结果随之更新。
  4. 返回：{ updated }。

3出错怎么办

情况结果码
会话不属于本插件调用失败，标题不变PERMISSION_DENIED
sessionId 不存在调用失败NOT_FOUND

4不提供什么

不能改其他插件/宿主会话。
