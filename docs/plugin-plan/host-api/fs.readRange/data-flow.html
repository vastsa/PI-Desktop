1接口约定

pi.fs.readRange(pathFromRoot: string, byteOffset: number, length: number, grantId?: string): Promise<PluginFsRange>

读一个文件中有界的字节区间。权限：—

入参

字段类型必填说明
pathFromRootstring是根相对路径；受读范围与拒绝列表约束。
byteOffsetnumber是起始字节偏移（参数名是 byteOffset，不是 offset）。
lengthnumber是要读取的字节数，区间有界。
grantIdstring否仅拖放授权（dropped-file grant）场景使用。

出参

字段类型说明
bytesUint8Array读到的字节区间。
totalSizenumber文件总字节数，便于判断是否已读到末尾。

输入样例

const head = await pi.fs.readRange("logs/app.log", 0, 4096);

输出样例

// bytes 为 Uint8Array（此处示意），totalSize 是文件总字节数
{ "bytes": <Uint8Array 4096 字节>, "totalSize": 946176 }
一句话边界。不给整个大文件；参数名是 byteOffset 不是 offset。

2数据怎么走

  1. 调用：插件传路径、byteOffset、length；拖放来的文件可带 grantId。
  2. 校验：按读范围与拒绝列表检查路径；byteOffset / length 必须是数字。
  3. 执行：宿主只读该字节区间，不载入全文。
  4. 返回：bytes 与 totalSize 回给插件。
方向内容
插件 → 宿主路径 + 起始偏移 + 长度（可选 grantId）。
宿主 → 插件字节区间 bytes + 文件总大小 totalSize。

3出错怎么办

情况结果码
缺少 fs.read，或路径不在读范围拒绝PERMISSION_DENIED
文件不存在拒绝NOT_FOUND
byteOffset / length 缺失或类型不符拒绝调用INVALID_ARGUMENT

4不提供什么

不给整个大文件；参数名是 byteOffset 不是 offset。
