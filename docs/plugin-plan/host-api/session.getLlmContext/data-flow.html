1接口约定

pi.session.getLlmContext(): Promise<PluginLlmContext>

读取当前进行中工具会话的 LLM 上下文投影（消息、模型、截断标记）。权限：—。

入参

无入参。

出参

字段类型说明
sessionIdstring当前工具会话 id。
modelKeystring | null当前模型键（providerId/modelId 形态），可为 null。
thinkingLevelstring当前思考档位，可缺省。
messagesPluginLlmMessage[]投影后的消息。数组元素结构：role（"user"|"assistant"|"tool"|"system"）、content、toolName?。
truncatedboolean投影是否被压缩截断。

输入样例

// 无入参

输出样例

{
  "sessionId": "tool_7d21",
  "modelKey": "anthropic/claude-sonnet-4-5",
  "thinkingLevel": "medium",
  "messages": [
    { "role": "user", "content": "重构 src/db.rs 的连接池" },
    { "role": "assistant", "content": "先看当前实现……" }
  ],
  "truncated": false
}
一句话边界。只读当前进行中的工具会话投影；不能按任意 sessionId 读历史全文，也不能写回。

2数据怎么走

  1. 调用：插件无参发起。
  2. 定位：宿主找当前进行中的工具会话；没有即 INVALID_ARGUMENT。
  3. 投影：生成压缩投影（D019 / D336），剥离插件自身的工具调用，不吐 subagent 轨道。
  4. 返回：PluginLlmContext；truncated: true 表示内容被压缩过。
方向内容
插件 → 宿主无参读取请求。
宿主 → 插件当前会话上下文投影 PluginLlmContext。

3出错怎么办

情况结果码
调用未被授权调用失败PERMISSION_DENIED
没有进行中的工具会话调用失败INVALID_ARGUMENT

4不提供什么

不能按任意 sessionId 读历史全文；不能覆盖写回。

宿主保证 / 已接受代价：宿主保证：投影剥离自身工具调用，不吐 subagent 轨道。已接受代价：只能读进行中工具会话。
