1接口约定

pi.audio.writeOutput(input: { streamId: string; data: Uint8Array }): Promise<void>

把一段 PCM16 字节排进本插件的播放队列，由宿主按序播放（权限：—）。

入参

字段类型必填说明
input.streamIdstring是openOutput 返回的播放会话 id。
input.dataUint8Array是PCM16 小端采样字节；多声道按声道交错排列，不接受浮点 PCM。

出参

字段类型说明
（返回值）Promise<void>无数据；resolve 表示字节已入队（不表示已播完）。

输入样例

// data 为 Uint8Array（PCM16 小端，多声道交错）
pi.audio.writeOutput({ streamId: "out-8c11d0", data: pcm16Bytes });

输出样例

// 无返回值
一句话边界。只接受 PCM16 交错字节；队列满时以 LIMIT_EXCEEDED 拒绝，不会静默丢弃。

2数据怎么走

  1. 调用：pi.audio.writeOutput({ streamId, data })。
  2. 校验：宿主核对权限（PERMISSION_DENIED）、会话存在性与字节格式（仅 PCM16 交错）。
  3. 执行：字节进入该会话的宿主播放队列，按序等待播放。
  4. 返回：resolve 表示已入队；队列满时以 LIMIT_EXCEEDED 拒绝，数据不静默丢弃。
方向内容
插件 → 宿主PCM16 字节（入队）。
宿主 → 系统按会话参数播放排队的音频。

3出错怎么办

情况结果码
插件未获音频播放权限调用失败（reject）PERMISSION_DENIED
宿主无音频后端调用失败（reject）UNSUPPORTED
播放队列已满调用失败（reject），字节不入队、不静默丢弃LIMIT_EXCEEDED

4不提供什么

不接受浮点 PCM；只接受交错（interleaved）布局，不接受平面（planar）布局。
