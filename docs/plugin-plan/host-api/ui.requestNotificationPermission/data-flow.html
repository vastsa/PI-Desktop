1接口约定

pi.ui.requestNotificationPermission(): Promise<PluginNotificationPermission>

请求通知权限，由宿主代理系统授权流程；权限：—。

入参

无入参。

出参

字段类型说明
（返回值）"granted" | "denied" | "unknown" | "unsupported"请求结束后的最新权限状态，取值同 getNotificationPermission。

// 无入参

2数据怎么走

  1. 调用：插件进程无参调用（通常先查 getNotificationPermission）。
  2. 校验：清单缺 notify 权限时拒绝。
  3. 执行：宿主代理系统权限流程，必要时弹出系统授权框；结果持久到系统/宿主策略。
  4. 返回：请求后的最新权限状态。
方向内容
插件 → 宿主授权请求（无参数）。
宿主 → 系统代理系统权限流程 / 授权框。
宿主 → 插件最新权限状态字符串。
