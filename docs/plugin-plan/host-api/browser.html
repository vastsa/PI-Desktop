对本插件访客页执行后退 / 前进 / 刷新 / 停止加载。权限：—。

入参

字段类型必填说明
action"back" | "forward" | "reload" | "stop"是浏览动作枚举，四选一。

出参

字段类型说明
（返回值）void无出参；Promise<void> 完成即动作已提交。

输入样例

输出样例

// 无出参（Promise<void>）
一句话边界。只对本插件访客页的浏览历史和加载状态生效，不能逃出访客页边界。

2数据怎么走

  1. 调用：插件执行 pi.browser.action({ action: "reload" })。
  2. 校验：宿主检查 action 是否为 back / forward / reload / stop 之一。
  3. 执行：宿主把对应浏览动作落到本插件面板绑定的访客页。
  4. 返回：Promise<void> 完成，无返回值；插件卸载后绑定失效。
方向内容
插件 → 宿主动作枚举（back / forward / reload / stop）。
