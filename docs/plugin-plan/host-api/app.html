1接口约定

pi.app.getAppearance(): Promise<PluginAppearance>

读取当前外观快照：主题偏好、解析后的明暗、语言与插件主题；权限：—。

入参

无入参。

出参

字段类型说明
themestring用户原始主题偏好："light" | "dark" | "system" | "plugin:<pluginId>:<themeId>"。
base"light" | "dark" | "system"解析后的明暗基调；"system" 表示尚未解析。
localestring当前应用语言标签。
pluginTheme{ id, base, css } | null激活的贡献主题；偏好未指向插件主题时为 null，子字段见下。
pluginTheme.idstring该主题 id。
pluginTheme.base"light" | "dark"该主题明暗基调。
pluginTheme.cssstring主题 CSS 正文。

输入样例

// 无入参

输出样例

{
   "theme": "plugin:pomodoro:forest",
   "base": "dark",
   "locale": "zh-CN",
   "pluginTheme": { "id": "plugin:pomodoro:forest", "base": "dark", "css": ":root{--bg:#0f1a12;}" }
 }
一句话边界。一次快照，不是订阅：变化靠 appearance:changed；不返回完整设计令牌表，也不暴露宿主内部色板 API。

2数据怎么走

  1. 调用：插件进程无参调用。
  2. 执行：宿主组装当前外观快照（主题偏好 + 解析明暗 + 语言 + 插件主题）。
  3. 返回：快照对象；之后外观变化经 appearance:changed 事件推送，插件需重新调用获取新快照。

3出错怎么办

一般不失败。

4不提供什么

不返回完整设计令牌表；不暴露宿主内部色板 API。

app.setThemeimplemented

status: implemented · 事实源 packages/plugin-sdk/src/index.ts · PluginHostApi

1接口约定

pi.app.setTheme(themeId: AppThemePreferenceId): Promise<void>

设置应用主题偏好（内置或已注册插件主题）；权限：—。

入参

字段类型必填说明
themeIdAppThemePreferenceId是"system" | "light" | "dark" | "plugin:<pluginId>:<themeId>"；只能选内置偏好或当前已注册的插件主题。

出参

字段类型说明
（返回值）void无返回数据，成功即 resolve。

输入样例

pi.app.setTheme("dark")

输出样例

// void —— 成功即 resolve，无输出
一句话边界。只能切到内置主题或本插件已注册主题；不删除主题、不改 CSS、不切换语言。

2数据怎么走

  1. 调用：插件进程传入 themeId。
  2. 校验：清单缺 ui.theme 权限或 themeId 格式非法时拒绝。
  3. 校验：plugin:… 形式需为当前已注册主题，否则按不存在处理。
  4. 执行：立即写入宿主主题偏好（ui.theme）。
  5. 返回：resolve；外观变化经 appearance:changed 广播。

3出错怎么办

情况结果码
清单缺 ui.theme 权限Promise 拒绝PERMISSION_DENIED
主题未注册Promise 拒绝，偏好不变NOT_FOUND
themeId 格式非法Promise 拒绝INVALID_ARGUMENT

4不提供什么

不删除主题、不改 CSS、不切换语言。
