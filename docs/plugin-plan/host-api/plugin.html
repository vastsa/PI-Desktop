返回本插件私有数据目录的绝对路径。权限：—。

入参

无入参。

出参

字段类型说明
（返回值）Promise<string>私有数据目录绝对路径，跨重启稳定；卸载时按打包策略处理。

输入样例

// 无入参

输出样例

// 目录具体布局由宿主决定，仅示意

一句话边界。这是插件私有目录，不是用户工作区——工作区文件仍要走 pi.fs.* 及其权限。

2数据怎么走

  1. 插件调用 pi.plugin.getDataPath()，无入参。
  2. 宿主按本插件 id 定位其私有数据目录。
  3. Promise 兑现为绝对路径；目录跨重启稳定，卸载时按打包策略处理。

3出错怎么办

定位既有目录，一般不失败。

不等于用户工作区；工作区文件仍走 pi.fs.*。

1接口约定

pi.plugin.getManifest(): PluginManifest

同步返回本插件安装时已通过校验的清单对象，不经过 Promise。权限：—。

入参

无入参。

出参

完整 PluginManifest 字段较多（含 contributes 声明块），此处只列常用键与权限声明类键；完整结构以 SDK 类型为准。

字段类型说明
idstring插件唯一 id，形如 demo.hello。
namestring作者原语言显示名，也是 i18n 缺失时的回落。
versionstring插件版本号。
permissionsstring[]?声明的权限名列表（如 fs.read、notify），可选。
fsPluginFsPolicy?文件读写范围声明；声明外的路径在调用时回落给用户确认。
net{ domains? }出网域名白名单；缺省或为空即不出网。

输入样例

// 无入参

输出样例

{
  "id": "demo.hello",
  "name": "Hello Demo",
  "version": "1.2.0",
  "permissions": ["fs.read", "notify"]
}
一句话边界。返回的是安装时校验后的只读快照——不读磁盘、不重新校验、运行中不可变，插件改不了清单。

2数据怎么走

  1. 插件在任意生命周期阶段调用 pi.plugin.getManifest()，无入参。
  2. 宿主返回安装时校验后的清单对象，进程内只读，不重新加载文件。
  3. 同步返回；对象运行中不可变。

3出错怎么办

同步读已加载对象，一般不失败。

4不提供什么

不读磁盘、不重校验、不能改清单。

pi.plugin.getSettings(): Promise<Record<string, unknown>>

读取本插件当前设置键值。权限：—。

入参

无入参。

出参

字段类型说明
（返回值）Promise<Record<string, unknown>>本插件设置键值对象；未设置的键按清单 contributes.settings 的 default 理解。

输入样例

// 无入参

输出样例

{
  "interval": 30,
  "mode": "auto"
}
一句话边界。只读本插件自己的设置——读不到其他插件的；secret 类型贡献项仍被校验拒绝。

2数据怎么走

  1. 插件调用 pi.plugin.getSettings()，无入参。
  2. 宿主按调用方身份圈定本插件设置作用域，不涉及其他插件。
  3. 每次调用都读宿主持久层，无本地缓存。
  4. Promise 兑现为键值对象；设置页编辑会触发 plugin:settingsChanged 事件，可监听后重读。
方向内容
插件 → 宿主无入参的读取请求。
宿主 → 插件Record<string, unknown> 设置键值。

3出错怎么办

情况结果码
宿主设置存储读异常Promise 拒绝INTERNAL

4不提供什么

不能读其他插件设置；secret 类型仍被校验拒绝。

1接口约定

pi.plugin.setSettings(partial: Record<string, unknown>): Promise<void>

按键合并写入本插件设置，落盘持久。权限：—。

入参

字段类型必填说明
partialRecord<string, unknown>是要更新的局部键值；只合并列出的键，其余不动。

出参

字段类型说明
（返回值）Promise<void>合并落盘后兑现，无返回数据。

输入样例

{ "interval": 30, "mode": "auto" }

输出样例

// 无返回值（Promise<void>）
一句话边界。合并语义而非整块替换——未提到的键原样保留；只能写本插件自己的设置。

2数据怎么走

  1. 插件传入要更新的局部键值对象。
  2. 校验：入参须为对象，非法则拒绝（INVALID_ARGUMENT）。
  3. 执行：按键合并进本插件设置并持久化，重启后仍在。
  4. Promise 兑现为 void。

3出错怎么办

情况结果码
入参不是对象 / 键值非法Promise 拒绝，设置不变INVALID_ARGUMENT

4不提供什么

不提供整块替换；不写其他插件。
