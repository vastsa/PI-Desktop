host-api · 插件可调用 API 全集

status: implemented · 事实源 packages/plugin-sdk/src/index.ts · PluginHostApi

0这份目录是什么

插件今天已经能调用的官方 API 全集。每条 API 一个文件夹，内含需求描述与数据流。与 插件插槽目录（界面 / render / 运行时）平行，互不覆盖。

项值
条目数95（PluginHostApi 方法 + PluginModule 钩子）
事实来源packages/plugin-sdk/src/index.ts · docs/spec/07-plugins/03-plugin-api.md
每文件夹index.html · requirements.html · data-flow.html
状态口径条目 implemented 表示 SDK 对外表面已存在；总表草稿状态不改变这一点
范围：只收录可调用 API 与生命周期钩子。清单声明（contributes.*）不是可调用 API。未实现的设计稿在 runtime/ 会话数据契约（session-context / session-compaction / session-model）；用量推送已结案——不新增，官方姿势见 usage.listTurns 第 2 节。
