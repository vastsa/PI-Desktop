commands.registerimplemented

status: implemented · 事实源 packages/plugin-sdk/src/index.ts · PluginHostApi

1接口约定

pi.commands.register(command: PluginCommand): Promise<void>

注册一条本插件命令：命令面板可见，也可作为全局快捷键目标。权限：—。

入参

字段类型必填说明
idstring是命令 id，本插件内唯一，注销时用它寻址。
titlestring是命令面板里显示的标题。
keywordsstring[]否便于面板搜索的附加关键词。
categorystring否面板里的分组名。
run() => Promise<void> | void是触发时执行的回调，留在插件进程，无参数无返回。

出参

字段类型说明
（返回值）Promise<void>登记成功后兑现，无返回数据。

输入样例

await pi.commands.register({
  id: "demo.hello.sync",
  title: "同步笔记",
  keywords: ["sync"],
  category: "笔记",
  run: async () => { /* 在插件进程执行 */ },
});

输出样例

// 无返回值（Promise<void>）
一句话边界。只能注册本插件自己的命令——改不了宿主命令，也不能替代全局快捷键注册（那走 keyboard.registerGlobalShortcut）。

2数据怎么走

  1. 插件把命令对象（含 run 回调）交给宿主登记。
  2. 校验：字段齐全合法，否则 INVALID_ARGUMENT；超过数量上限则 LIMIT_EXCEEDED。
  3. 登记持续到 commands.unregister 或插件卸载。
  4. 用户在命令面板触发时，宿主回到插件进程执行 run。
方向内容
插件 → 宿主命令对象（id、title、keywords?、category?、run 回调）。
宿主 → 插件用户触发命令时调用 run，无参数、无返回值。

3出错怎么办

情况结果码
入参缺字段或类型不对Promise 拒绝，登记不生效INVALID_ARGUMENT
超出宿主允许的命令数量上限Promise 拒绝，登记不生效LIMIT_EXCEEDED

4不提供什么

不能改宿主命令；不能替代全局快捷键注册。

1接口约定

pi.commands.unregister(id: string): Promise<void>

注销一条本插件已注册的命令。权限：—。

入参

字段类型必填说明
idstring是要注销的命令 id，与 register 时一致。

出参

字段类型说明
（返回值）Promise<void>注销完成后兑现，无返回数据。

输入样例

await pi.commands.unregister("demo.hello.sync");

输出样例

// 无返回值（Promise<void>）
一句话边界。只能注销本插件自己的命令，宿主命令不受影响；插件卸载时宿主强制清理全部命令。

2数据怎么走

  1. 插件传入命令 id。
  2. 宿主立即把命令从命令面板移除。
  3. 已绑定到这条命令的全局快捷键按宿主策略释放。
  4. Promise 兑现为 void。

3出错怎么办

情况结果码
id 未注册静默成功，不报错—

4不提供什么

不能注销宿主命令。

  • host-api/commands.register

无。

场景插件做什么

  • 与 register 成对；卸载时宿主强制清理。
