1接口约定

pi.app.getAppearance(): Promise<PluginAppearance>

读取当前外观快照：主题偏好、解析后的明暗、语言与插件主题；权限：—。

入参

无入参。

出参

字段类型说明
themestring用户原始主题偏好："light" | "dark" | "system" | "plugin:<pluginId>:<themeId>"。
base"light" | "dark" | "system"解析后的明暗基调；"system" 表示尚未解析。
localestring当前应用语言标签。
pluginTheme{ id, base, css } | null激活的贡献主题；偏好未指向插件主题时为 null，子字段见下。
pluginTheme.idstring该主题 id。
pluginTheme.base"light" | "dark"该主题明暗基调。
pluginTheme.cssstring主题 CSS 正文。

输入样例

// 无入参

输出样例

{
   "theme": "plugin:pomodoro:forest",
   "base": "dark",
   "locale": "zh-CN",
   "pluginTheme": { "id": "plugin:pomodoro:forest", "base": "dark", "css": ":root{--bg:#0f1a12;}" }
 }
一句话边界。一次快照，不是订阅：变化靠 appearance:changed；不返回完整设计令牌表，也不暴露宿主内部色板 API。

2数据怎么走

  1. 调用：插件进程无参调用。
  2. 执行：宿主组装当前外观快照（主题偏好 + 解析明暗 + 语言 + 插件主题）。
  3. 返回：快照对象；之后外观变化经 appearance:changed 事件推送，插件需重新调用获取新快照。

3出错怎么办

一般不失败。

4不提供什么

不返回完整设计令牌表；不暴露宿主内部色板 API。
