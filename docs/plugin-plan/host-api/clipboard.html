clipboard.getHistoryimplemented

status: implemented · 事实源 packages/plugin-sdk/src/index.ts · PluginHostApi

1接口约定

pi.clipboard.getHistory(): Promise<ClipboardHistoryEntry[]>

读宿主保留的剪贴板历史（权限：—；历史可能含敏感信息，权限为 clipboard.read）。

无入参。

出参

字段类型说明
（返回值）ClipboardHistoryEntry[]历史条目数组；数组元素结构是判别联合，见下列字段。
type"text" | "image"判别字段：文本条目或图片条目。
textstring仅 type: "text"：文本内容。
format"png" | "jpeg" | "webp"仅 type: "image"：图片格式。
dataUint8Array仅 type: "image"：图片字节。
width / heightnumber仅 type: "image"：像素尺寸。
capturedAtstring两种变体都有：捕获时间。

输入样例

// 无入参

输出样例

[
  { "type": "text", "text": "部署已回滚", "capturedAt": "2026-02-16T09:12:00.000Z" },
  { "type": "image", "format": "png", "data": [137, 80, 78, 71], "width": 640, "height": 400, "capturedAt": "2026-02-16T09:10:41.000Z" }
]
一句话边界。只读宿主保留窗口内的历史（30 天 / 500 条 / 256 MiB 上界），不轮询系统剪贴板；没有删除历史的 API。

2数据怎么走

  1. 调用：插件进程发起 pi.clipboard.getHistory()。
  2. 校验：宿主检查读侧权限（clipboard.read）。
  3. 执行：宿主返回自己保留的剪贴板历史快照，有界（30 天 / 500 条 / 256 MiB）；宿主不轮询操作系统剪贴板。
  4. 返回：条目数组一次给全，无游标、无分页；文本与图片条目按 type 判别。
方向内容
插件 → 宿主无入参，仅调用。
宿主 → 插件ClipboardHistoryEntry[]。

3出错怎么办

情况结果码
读侧权限不满足Promise 拒绝，不返回历史PERMISSION_DENIED

4不提供什么

当前表面没有删除历史 API。

宿主保证 / 已接受代价：宿主保证：历史有界（30 天 / 500 条 / 256 MiB），不轮询操作系统剪贴板。已接受代价：更早的历史拿不到。

status: implemented · 事实源 packages/plugin-sdk/src/index.ts · PluginHostApi

1接口约定

pi.clipboard.readText(): Promise<string>

读当前系统剪贴板的文本快照（权限：—；读侧权限独立，可能读到敏感内容，首次使用时向用户确认）。

无入参。

出参

字段类型说明
（返回值）string当前剪贴板中的文本；剪贴板是图片时拿不到正文（见第 4 节）。

输入样例

// 无入参

输出样例

"会议纪要：下周三 10:00 评审"
一句话边界。只读文本：没有读图片剪贴板正文的 API，图片请走 clipboard.getHistory。

2数据怎么走

  1. 调用：插件进程发起 pi.clipboard.readText()。
  2. 校验：宿主检查读侧权限；首次使用时向用户确认（剪贴板可能含敏感信息）。
  3. 执行：宿主读取当前系统剪贴板文本，返回一次快照；不随剪贴板变化推送。
  4. 返回：文本字符串；调用方需要再次数据时重新调用。
方向内容
插件 → 宿主无入参，仅调用。
宿主 → 系统读取系统剪贴板文本。
宿主 → 插件文本字符串。

3出错怎么办

情况结果码
读侧权限不满足（或用户拒绝确认）Promise 拒绝，不读取PERMISSION_DENIED

4不提供什么

不读图片剪贴板正文 API。

1接口约定

pi.clipboard.writeText(text: string): Promise<void>

把一段文本写入系统剪贴板（权限：—；写侧权限独立，与读分离）。

入参

字段类型必填说明
textstring是要写入的文本，位置参数。

出参

字段类型说明
（返回值）void无返回数据，成功即 resolve。

输入样例

pi.clipboard.writeText("已生成的内容")

输出样例

// void —— 成功即 resolve，无输出
一句话边界。覆盖式写入系统剪贴板；不提供历史清理（历史读取另有 clipboard.getHistory）。

2数据怎么走

  1. 调用：插件进程传入 text。
  2. 校验：宿主检查写侧权限（与读分离）。
  3. 执行：宿主把文本写入系统剪贴板，覆盖原有内容。
  4. 返回：无回执值；写入结果由 resolve / reject 表达。
方向内容
插件 → 宿主文本字符串。
宿主 → 系统覆盖系统剪贴板。

3出错怎么办

情况结果码
写侧权限不满足Promise 拒绝，不写入PERMISSION_DENIED

4不提供什么

不提供历史清理。
