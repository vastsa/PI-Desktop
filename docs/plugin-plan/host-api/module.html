onLoad?: () => Promise<void> | void  // PluginModule 可选钩子

插件被加载或启用时，宿主调用一次的初始化钩子；无需声明任何权限。—

无入参。宿主 API 不经参数传入：插件进程在加载模块前已把宿主 API 挂到 globalThis.pi，钩子里直接用 pi.*。

出参

字段类型说明

输入样例

// 插件侧最小实现（pi 来自 globalThis）
async onLoad() {
  await pi.commands.register({ id: "greet", title: "打招呼", run: () => pi.ui.showToast("你好", "info") })
}

2数据怎么走

  1. 调用。宿主加载或启用插件时调用一次 onLoad，无参数。
  2. 执行。插件在钩子内通过 pi 注册命令、工具、服务等贡献点，注册随调用陆续生效。

插件 → 宿主经 pi 发出的注册请求；钩子本身无返回值。

1接口约定

onPanelInvoke?: (channel: string, payload: unknown) => Promise<unknown> | unknown  // PluginModule 可选钩子

隔离面板页与插件之间的固定通道调用入口；面板能力不因该钩子扩大，无需声明任何权限。—

入参

字段类型必填说明
channelstring是通道名，由插件自己约定（固定通道，非通用 IPC）。
payloadunknown是面板页随调用携带的数据；可为空值，结构由插件约定。

出参

字段类型说明
（返回值）Promise<unknown> | unknown处理结果，结构由插件实现决定，原样回传面板页。

输入样例

// 宿主调用：转发面板页的固定通道调用
module.onPanelInvoke("submit", { title: "周报", count: 3 })

// 插件侧最小实现
onPanelInvoke(channel, payload) {
  if (channel === "submit") return { ok: true, saved: payload.title }
  throw new Error("未知通道: " + channel)
}

输出样例

// 返回类型为 unknown，结构由插件实现自定义
{ "ok": true, "saved": "周报" }
一句话边界。不是通用 IPC：通道语义由插件自己约定，宿主不借它暴露 plugin.setSettings、fs.remove 或任意 Electron IPC。

2数据怎么走

  1. 调用。面板打开期间（ui.openPanel 打开的隔离沙箱页），面板页经固定通道发起调用。
  2. 转发。宿主把通道名与数据转发给插件主模块的 onPanelInvoke；面板页是沙箱页，不直接访问插件进程。
  3. 执行。插件按 channel 分发处理，payload 结构由插件约定。
  4. 返回。处理结果（可 async）回传面板页；通道未处理按宿主错误模型返回。
方向内容
宿主 → 插件channel 通道名与 payload 数据。
插件 → 宿主处理结果，原样回传面板页。

3出错怎么办

无错误码。通道未处理时，按宿主错误模型返回给面板页。

4不提供什么

不是通用 IPC；通道由插件自己约定。

宿主保证 / 已接受代价：宿主保证：不暴露 `plugin.setSettings`、`fs.remove` 或任意 Electron IPC。已接受代价：通道由插件自己约定。

1接口约定

onUnload?: () => Promise<void> | void  // PluginModule 可选钩子

插件停用或卸载前，宿主调用一次的清理钩子；无需声明任何权限。—

无入参。

出参

字段类型说明
（返回值）Promise<void> | void无返回值；可返回 Promise，宿主等待其完成或超时。

输入样例

// 宿主调用：停用/卸载前触发
module.onUnload()

// 插件侧最小实现
onUnload() {
  clearInterval(this.timer)
}

输出样例

// 无返回值
一句话边界。不能阻止卸载：宿主仍会强制清理命令、工具、快捷键，并关闭插件仍持有的套接字。

2数据怎么走

  1. 调用。宿主停用或卸载插件前触发一次，无入参。
  2. 执行。插件停掉自己启动的定时器、连接、服务等资源。
  3. 预算。钩子约 5 秒预算；超时或抛错后宿主继续往下走。
  4. 兜底。无论钩子结果如何，宿主都会强制清理该插件注册的命令、工具、快捷键，并关闭它仍持有的套接字。
方向内容
宿主 → 插件停用/卸载调用信号（无参数）。
插件 → 宿主无返回值；仅清理自身资源。

3出错怎么办

无错误码。钩子超时或抛错后，宿主继续清理。

4不提供什么

不能阻止卸载。
