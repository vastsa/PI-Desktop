入参

出参

字段类型说明
（返回值）void同步注册，立即返回，无数据。

输入样例

输出样例

// 无返回值
一句话边界。注册的是处理函数，不是事件名；不给设备句柄，sequence 出现缺口即表示宿主丢帧（不重排）。

2数据怎么走

  1. 调用：pi.audio.onInputFrame(handler)，同步注册、立即返回 void。
  2. 校验：宿主无音频后端时同步抛 Error（code: "UNSUPPORTED"）——不是事件订阅，不能靠 events 监听。
  3. 执行：采集期间宿主按采集节奏向 handler 推送 PluginAudioInputFrame；handler 落后时宿主丢帧，sequence 出现缺口（不重排）。
  4. 解除：调用 offInputFrame 传同一函数引用，或插件被禁用 / 卸载。
方向内容
宿主 → 插件PCM16 帧（采集节奏推送，落后即丢）。
插件 → 宿主无数据上行，仅注册 / 注销 handler。

3出错怎么办

  4. 返回：resolve 表示已入队；队列满时以 LIMIT_EXCEEDED 拒绝，数据不静默丢弃。
方向内容
插件 → 宿主PCM16 字节（入队）。
宿主 → 系统按会话参数播放排队的音频。

3出错怎么办

情况结果码
插件未获音频播放权限调用失败（reject）PERMISSION_DENIED
宿主无音频后端调用失败（reject）UNSUPPORTED
播放队列已满调用失败（reject），字节不入队、不静默丢弃LIMIT_EXCEEDED

4不提供什么

不接受浮点 PCM；只接受交错（interleaved）布局，不接受平面（planar）布局。
